Grammar Checker Extensions for LibreOffice

LibreOffice offers robust writing tools, but its default spell checker lacks the advanced contextual grammar, style, and syntax checking required for professional drafting. This guide covers the top extensions and built-in integration methods that bring advanced, LanguageTool-like grammar and style checking directly into LibreOffice Writer.

1. LanguageTool (Native API and Official Extension)

LanguageTool is the leading open-source grammar and style checker. LibreOffice supports LanguageTool in two distinct ways:

  • Direct API Integration (LibreOffice 7.4 and newer): Modern versions of LibreOffice Writer have built-in support for LanguageTool via a local or remote server. Users can navigate to Tools > Options > Language Settings > LanguageTool Server and activate checking by connecting to the public LanguageTool API or a self-hosted instance. This method avoids the need for Java dependencies.
  • The LanguageTool Extension (.oxt): For older versions or offline setups, the official Java-based .oxt extension runs locally within LibreOffice. It detects grammar errors, punctuation mistakes, commonly confused words, and stylistic issues across more than 30 languages.

2. Grammalecte

Grammalecte is a dedicated, highly advanced grammar and typography checker designed specifically for the French language. Similar to LanguageTool, it operates as a full-featured LibreOffice extension.

  • Features: It detects grammatical agreements, conjugation errors, improper punctuation, redundancy, and typographical spacing issues according to French standards.
  • Integration: It includes a dedicated conjugation tool, text formatter, and dictionary manager directly inside LibreOffice Writer.

3. Lightproof

Lightproof is LibreOffice's default rule-based grammar checking engine, written in Python. While more lightweight than LanguageTool, it provides baseline grammar and style checking without requiring third-party cloud connections.

  • Features: It flags common syntactic mistakes, spacing anomalies, passive voice overuse, and repeated words.
  • Language Support: Rules are available for English, Hungarian, Russian, and several other languages, accessible under the standard LibreOffice language settings.

4. CoGrOO (Community Grammar OpenOffice)

For Portuguese writers, CoGrOO provides deep syntactic and morphological analysis within LibreOffice.

  • Features: Powered by natural language processing (NLP), CoGrOO analyzes the structural context of sentences to catch subject-verb agreement issues, nominal concordance, and pronoun placement errors.
  • Format: Available as an .oxt extension that integrates seamlessly into Writer’s context menu.

5. Duden Korrektor (Commercial)

For German language users requiring enterprise-grade accuracy, Duden Korrektor is the industry standard.

  • Features: It offers comprehensive orthographic, grammatical, and stylistic proofreading based on the official Duden dictionary and grammar rules.
  • Format: Available as a commercial plugin that embeds directly into the LibreOffice interface.
