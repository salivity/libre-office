Connect Cloud Storage to LibreOffice

LibreOffice allows users to open, edit, and save documents directly to remote cloud storage systems without needing local synchronization folders. Through its built-in remote file management feature, LibreOffice connects directly to popular cloud platforms and network servers using native API connectors and standard network transfer protocols.

Supported Cloud Services and Protocols

LibreOffice includes a "Remote Files" dialog that natively supports several cloud storage solutions and protocols:

  • Google Drive: LibreOffice includes dedicated integration for Google Drive. Users can authenticate using their Google account credentials and two-factor authentication to browse, open, and save files directly to Google's cloud storage.
  • Nextcloud and ownCloud: These self-hosted and enterprise cloud platforms connect seamlessly using the WebDAV protocol. Users can manage remote files by entering their server URL and account credentials.
  • Generic WebDAV: Any cloud storage provider or web server supporting WebDAV (such as Koofr, pCloud via WebDAV endpoints, or custom Apache/Nginx WebDAV setups) can be mounted directly.
  • SSH / SFTP: Secure File Transfer Protocol allows direct access to files hosted on cloud virtual private servers (VPS), dedicated Linux servers, or cloud instances across AWS, DigitalOcean, and Linode.
  • FTP and FTPS: Standard and SSL-encrypted File Transfer Protocol connections can be configured to access remote web hosts and legacy storage servers.
  • Windows Share (SMB/CIFS): Cloud-hosted or local network shares running Server Message Block (SMB) can be integrated into the LibreOffice file manager.

How to Add Cloud Storage in LibreOffice

To mount any of the supported services directly inside the LibreOffice file picker:

  1. Open LibreOffice.
  2. Go to File in the top menu and select Open Remote File (or Save Remote).
  3. In the Remote Files dialog, click Manage Services or Add Service.
  4. Select the service type from the dropdown menu (e.g., Google Drive, WebDAV, SSH).
  5. Enter the required connection details, including host URL, port, username, and password.
  6. Click OK to authenticate and save the connection.

Once added, the service will appear in the remote file browser, allowing you to access and modify your cloud-hosted files within LibreOffice.
