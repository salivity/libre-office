How to Add Drop Caps in LibreOffice Writer

Drop caps add a polished, professional look to the beginning of book chapters and articles by enlarging the first letter of an opening paragraph. This guide walks you through the exact steps to enable and customize drop caps in LibreOffice Writer, either for individual paragraphs using direct formatting or globally across all chapters using paragraph styles.

Method 1: Apply Drop Caps to a Single Paragraph

If you only need a drop cap for a specific chapter opener, use direct paragraph formatting:

  1. Click anywhere inside the first paragraph of your chapter.
  2. Go to the top menu and select Format > Paragraph (or right-click the paragraph and select Paragraph > Paragraph).
  3. In the dialog window, click on the Drop Caps tab.
  4. Check the box next to Display drop caps.
  5. Adjust the drop cap settings to fit your layout:
    • Lines: Sets how many lines of text tall the drop cap will be (default is usually 3).
    • Number of characters: Set to 1 for just the first letter, or increase it to include an entire first word.
    • Distance to text: Defines the horizontal spacing between the drop cap and the following text.
    • Character Style: Choose a specific font style or color for the drop cap (such as Drop Caps or a custom style).
  6. Click OK to apply the changes.

Method 2: Apply Drop Caps Using Paragraph Styles (Recommended)

Using styles ensures consistent formatting across every chapter in your document:

  1. Open the Styles sidebar by pressing F11 or clicking View > Styles.
  2. Click the Paragraph Styles icon at the top of the sidebar.
  3. Locate the style used for the beginning of your chapters (such as First Paragraph or Text Body).
  4. Right-click the style name and select Modify... (or Edit Style...).
  5. Navigate to the Drop Caps tab.
  6. Check Display drop caps and configure your preferred line height, character count, distance, and character style.
  7. Click Apply and then OK.
  8. Apply this paragraph style to the first paragraph of each chapter in your document.

How to Remove Drop Caps

To remove a drop cap:

  1. Select the paragraph or edit the associated paragraph style.
  2. Open the Paragraph dialog and go to the Drop Caps tab.
  3. Uncheck Display drop caps.
  4. Click OK.
