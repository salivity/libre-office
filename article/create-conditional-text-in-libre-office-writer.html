Create Conditional Text in LibreOffice Writer

LibreOffice Writer allows you to dynamically display different text strings or entire paragraphs based on predefined variable values. This feature is useful for creating automated document templates, personalized letters, and contracts that adapt based on specific conditions. This guide outlines the exact steps to define a variable and insert conditional text fields to control your document's output.

Step 1: Define a User Variable

Before creating conditional text, you must define the variable that the condition will evaluate.

  1. Place your cursor where you want to set the variable (usually at the beginning of the document).
  2. Open the Fields dialog by pressing Ctrl + F2 (or navigate to Insert > Field > More Fields...).
  3. Select the Variables tab.
  4. In the Type column, click on Set Variable.
  5. In the Format column, select Text or General depending on your variable type.
  6. Enter a name in the Name field (e.g., UserType).
  7. Enter an initial value in the Value field (e.g., Admin).
  8. Check the Invisible box if you do not want this variable definition to appear on the printed page.
  9. Click Insert, then close the dialog.

Step 2: Insert the Conditional Text Field

Once the variable exists, configure the conditional text field to evaluate its state.

  1. Place the cursor where you want the dynamic text to appear.
  2. Press Ctrl + F2 to open the More Fields dialog again.
  3. Select the Functions tab.
  4. In the Type list, choose Conditional text.
  5. In the Condition box, enter your logical expression. Use standard comparison operators (such as ==, !=, <, >):
    • Example for text variables: UserType == "Admin"
    • Example for numeric variables: UserType == 1
  6. In the Then box, type the text that should appear when the condition is true (e.g., Welcome, Administrator).
  7. In the Else box, type the text that should appear when the condition is false (e.g., Welcome, Guest).
  8. Click Insert, then click Close.

Step 3: Hide Entire Paragraphs (Optional)

If you need to show or hide entire blocks of text rather than inline words:

  1. Select the Functions tab in the More Fields dialog (Ctrl + F2).
  2. Select Hidden Paragraph in the Type list.
  3. In the Condition field, write the condition under which the paragraph should be hidden (e.g., UserType != "Admin").
  4. Click Insert inside the target paragraph.

Step 4: Test and Update the Condition

  1. Double-click the gray field box representing your variable definition to open the edit dialog.
  2. Change the value in the Value box and click OK.
  3. Press F9 on your keyboard to refresh all fields in the document. The conditional text will immediately update to match the new variable state.
