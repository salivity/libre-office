Export Diagrams to Vector EPS in LibreOffice Draw

Exporting technical diagrams from LibreOffice Draw to Encapsulated PostScript (EPS) format allows you to retain crisp vector graphics for academic papers, LaTeX documents, and high-resolution publications. LibreOffice Draw includes a native export engine that converts your shapes, lines, and text directly into vector-based EPS files without rasterizing your artwork.

Step 1: Prepare Your Diagram

  1. Open your diagram in LibreOffice Draw.
  2. If you only want to export a specific part of your drawing, select the relevant shapes and objects by dragging a selection box over them or holding Shift while clicking each element.
  3. If you want to export the entire page, ensure nothing is selected or prepare the page margins accordingly via Page > Properties.

Step 2: Open the Export Dialog

  1. Click on File in the top menu bar.
  2. Select Export... (do not select Export as PDF).
  3. In the file browser window, navigate to the folder where you want to save the file.
  4. Enter your desired file name.

Step 3: Select the EPS File Format

  1. Click the Save as type (or Filter) drop-down menu.
  2. Choose Encapsulated PostScript (.eps) from the list.
  3. If you selected specific objects in Step 1, check the Selection box at the bottom of the dialog window. This ensures only the selected objects are exported rather than the entire canvas.
  4. Click Save.

Step 4: Configure EPS Options

After clicking Save, the EPS Export Options dialog appears:

  • Preview: Choose whether to include an image preview (e.g., TIFF or EPSI). Including a TIFF preview makes the EPS easier to view in word processors, though it slightly increases file size.
  • Color Format: Select Color for full-color diagrams or Grayscale if submitting to a black-and-white publication.
  • PostScript Level: Choose Level 2 for broad compatibility or Level 3 if you require advanced gradient and transparency support.

Click OK to complete the export.

Tips for Best Vector Results

  • Text Handling: Text elements remain as editable text or native vector glyphs. To prevent font substitution issues across different platforms, use standard system fonts or convert critical text shapes to curves via Shape > Convert > To Curve prior to exporting.
  • Line Widths and Markers: Ensure line weights and arrowheads are scaled appropriately, as vector EPS files will maintain precise geometric proportions regardless of how much you scale them in your final document.
