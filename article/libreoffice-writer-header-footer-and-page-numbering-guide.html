LibreOffice Writer Header Footer and Page Numbering Guide

LibreOffice Writer provides extensive customization tools for document headers, footers, and page numbers, allowing users to create professional layouts tailored to books, academic papers, and business reports. By utilizing page styles, dynamic fields, and layout formatting tools, you can control numbering formats, display different content on odd and even pages, suppress headers on title pages, and start page counts at arbitrary positions in your document.

Enabling and Formatting Headers and Footers

To add a header or footer in LibreOffice Writer, navigate to Insert > Header and Footer and select the appropriate page style (typically Default Page Style). You can also click in the top or bottom margin area of any page and click the small tab that appears.

Once enabled, you can customize the layout via Format > Page Style under the Header or Footer tabs:

  • Margins and Spacing: Adjust the top/bottom margins and the spacing between the header/footer and the main text body.
  • AutoFit Height: Allow the area to expand dynamically as text is added, or set a fixed height.
  • Borders and Backgrounds: Apply custom border lines (such as a dividing rule beneath a header) or background colors and gradients.
  • Independent Left and Right Layouts: Uncheck Same content on left and right pages to create mirrored headers/footers for double-sided printing.
  • First Page Differentiation: Uncheck Same content on first page to keep the opening page clean without creating a separate page style.

Inserting and Styling Page Numbers

Page numbers in LibreOffice are dynamic fields rather than static text.

  1. Click inside the header or footer where you want the number to appear.
  2. Go to Insert > Field > Page Number.
  3. To display a total count (e.g., "Page 1 of 10"), type " of " after the number and go to Insert > Field > Page Count.

To change the numbering format (e.g., from Arabic numbers to Roman numerals i, ii, iii or letters A, B, C):

  1. Go to Format > Page Style and select the Page tab.
  2. Under the Layout Settings section, locate the Numbering dropdown menu.
  3. Select your preferred numbering scheme.

Changing Starting Page Numbers and Offsetting Counts

To start numbering from a specific number (such as starting page numbering at "1" on the third physical page):

  1. Place the cursor at the very beginning of the page where the restart should occur.
  2. Go to Insert > More Breaks > Manual Break.
  3. Select Page break.
  4. Choose the target Page Style (such as Default Page Style).
  5. Check Change page number and set the desired start number (e.g., 1).
  6. Click OK.

Dynamic Fields and Header Content Alignment

Headers and footers support predefined tab stops for standard alignments:

  • Pressing Tab once moves the cursor to the center alignment position.
  • Pressing Tab a second time moves the cursor to the right margin.

Beyond page numbers, you can insert dynamic document metadata by choosing Insert > Field:

  • Document Title / Subject: Automatically syncs with the document's file properties.
  • Date and Time: Can be fixed or updated automatically on print/save.
  • Author: Displays the name saved in user profile settings.
  • Chapter Name and Number: Select Insert > Field > More Fields > Document tab > Chapter to automatically display the current heading in the header.
