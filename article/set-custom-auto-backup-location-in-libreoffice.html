Set Custom Auto Backup Location in LibreOffice

LibreOffice provides built-in tools to safeguard your work by creating automatic backup copies every time you save a document. By default, these files are placed in a hidden system directory, but you can easily redirect them to a custom location—such as a dedicated folder, external drive, or cloud-synced directory—while ensuring automatic backups are properly enabled.

Step 1: Enable Automatic Backups

Before specifying a custom directory, you must configure LibreOffice to generate backup copies automatically.

  1. Open LibreOffice.
  2. Go to the menu bar and click Tools > Options (on macOS, go to LibreOffice > Preferences).
  3. In the left-hand sidebar, expand the Load/Save section and select General.
  4. Under the Save heading on the right, check the box labeled Always create backup copy.
  5. (Optional) Ensure Save AutoRecovery information every is checked and set your preferred interval (e.g., 5 or 10 minutes) for crash protection.

Step 2: Set a Custom Backup Directory

Once backup creation is enabled, change the storage path to your preferred folder.

  1. In the same Options (or Preferences) window, expand the LibreOffice section in the left sidebar.
  2. Click on Paths.
  3. In the list of paths displayed on the right, click on Backups.
  4. Click the Edit... button located in the bottom-right corner.
  5. In the file browser window, navigate to your desired custom backup folder (or create a new one) and click Select Folder (or Open).
  6. Click Apply, then click OK to save your new settings.

How LibreOffice Backups Work

  • When Backups Are Created: When you open an existing document and save changes, LibreOffice replaces the backup file in your custom folder with the version from your previous save state.
  • File Extension: Backups are stored with the .bak extension.
  • Restoring a File: To restore a file, navigate to your custom backup folder, right-click the .bak file, and open it with LibreOffice, or rename the .bak extension back to its original format (such as .odt, .docx, or .ods).
