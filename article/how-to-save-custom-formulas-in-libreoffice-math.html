How to Save Custom Formulas in LibreOffice Math

LibreOffice Math allows users to streamline their workflow by saving frequently used formula expressions and custom symbols for quick reuse. This guide walks you through the exact steps required to customize your Elements catalog, define new formula snippets or symbols, and insert them directly into your documents without having to retype complex syntax.

Accessing the Formula Catalog

To begin adding reusable items to your formula environment:

  1. Open LibreOffice Math directly or insert a Formula object in LibreOffice Writer via Insert > Object > Formula.
  2. Open the Elements pane by selecting View > Elements if it is not already visible.
  3. Open the catalog editor by selecting Tools > Catalog from the top menu bar, or by clicking the Symbols (Greek letter Omega or Sigma) icon on the standard toolbar.

Adding a Custom Symbol or Snippet

  1. In the Symbols dialog window, click the Edit... button to open the Edit Symbols interface.
  2. Choose an existing symbol set from the Symbol set drop-down menu, or type a new name into the field to create a dedicated custom category for your snippets.
  3. In the Symbol field, enter a unique identifier or command name for your custom item.
  4. Select the desired font family, subset, and character code from the preview grid.
  5. Click the Add button to register the new item into the selected set.
  6. Click OK to save the changes and close the editor dialog.

Reusing Saved Elements in Math Formulas

Once saved, your custom elements are immediately available for use in any formula:

  • Via the Interface: Open Tools > Catalog, choose your custom symbol set from the drop-down menu, select the item, and click Insert.
  • Via Direct Syntax: Type %YourSymbolName directly into the lower Formula Commands pane (for example, %mysnippet), and LibreOffice Math will automatically render the corresponding catalog element in the preview area.
