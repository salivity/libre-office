How to Fit a Spreadsheet on One Page in LibreOffice Calc

Printing a large spreadsheet often results in data being split awkwardly across multiple pages. LibreOffice Calc provides built-in page scaling features that automatically shrink your rows and columns so an entire sheet fits onto a single printed page. By adjusting the page style settings or using the print preview options, you can quickly condense multi-page datasets for efficient physical printing or PDF export.

Method 1: Adjust Page Style Settings

The primary and most reliable way to force a spreadsheet onto a single page is through the Page Style menu:

  1. Open your spreadsheet in LibreOffice Calc.
  2. Navigate to the top menu and select Format > Page Style.
  3. In the window that opens, click on the Sheet tab.
  4. Locate the Scale section at the bottom.
  5. Open the Scaling mode dropdown menu and select Fit print range(s) on number of pages.
  6. Set the Number of pages value to 1.
  7. Click OK to apply the configuration.

Method 2: Adjust via Print Preview

You can verify and adjust the layout visually before sending the document to the printer:

  1. Open Print Preview by clicking File > Print Preview or pressing Ctrl + Shift + O (Cmd + Shift + O on macOS).
  2. Click the Format Page button on the preview toolbar.
  3. Switch to the Sheet tab.
  4. Change the Scaling mode to Fit print range(s) on number of pages and ensure the page count is set to 1.
  5. Click OK to return to the preview and confirm that all data fits on one page.

Optimizing Your Layout for Readability

Condensing a large amount of data onto one page can make text difficult to read. To maximize space and improve legibility:

  • Switch to Landscape: If your spreadsheet has many columns, go to Format > Page Style > Page tab and set the orientation to Landscape.
  • Narrow the Margins: Under the Page tab in the Page Style menu, decrease the left, right, top, and bottom margins to expand the usable printable area.
  • Set a Print Range: If you only need a specific portion of the data, select the relevant cells and go to Format > Print Ranges > Define before printing.
