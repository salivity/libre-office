LibreOffice Writer Bibliography and Citation Tools

LibreOffice Writer provides a robust set of native features alongside third-party plugin integrations to help users create, manage, and format citations and bibliographies. Whether you are drafting a simple essay or a complex academic thesis, you can choose between Writer's built-in reference database system or powerful external reference managers depending on the scale and complexity of your project.

Built-In Citation and Bibliography Tools

LibreOffice Writer includes native functionality that allows you to manage references directly within the software without installing external add-ons.

1. The Built-in Bibliography Database

Writer comes with an integrated database to store source records such as books, journals, reports, and websites.

  • Accessing the Database: Navigate to Tools > Bibliography Database.
  • Managing Records: You can add new entries, edit metadata (e.g., author, title, publication year, ISBN), and define key identifiers used for in-text citations.

2. Inserting Bibliography Entries (In-Text Citations)

Once sources are saved or defined, you can insert in-text citations anywhere in your document.

  • How to Insert: Go to Insert > Table of Contents and Index > Bibliography Entry.
  • Source Selection: You can choose to insert a reference from the global Bibliography Database or define a temporary entry stored only within the current Document Content.
  • Short Name Keys: Citations are typically referenced using a short identifier that links the text directly to the generated reference list.

3. Generating and Customizing the Bibliography Table

When your writing is complete, you can automatically generate a formatted bibliography list.

  • How to Generate: Go to Insert > Table of Contents and Index > Table of Contents, Index or Bibliography.
  • Configuration: In the dialog box, set the Type to Bibliography.
  • Formatting Options: Under the Entries tab, you can customize the structure, sort order, and punctuation of the citations to align with styles like APA, MLA, or Chicago.

Third-Party Reference Management Extensions

For advanced academic workflows requiring automated formatting across thousands of citation styles, LibreOffice Writer supports several leading reference management tools via official extensions.

1. Zotero

Zotero is a free, open-source reference manager widely used in academia. Its LibreOffice extension adds a dedicated toolbar inside Writer that allows users to:

  • Search and insert in-text citations instantly from a personal library.
  • Automatically update and format bibliographies in over 10,000 citation styles.
  • Sync references across multiple devices and collaborate with other researchers.

2. Mendeley

Mendeley provides a LibreOffice plugin through its desktop application. It offers:

  • Fast citation insertion via a search dialog.
  • Automated bibliography generation.
  • Cloud synchronization and PDF annotation tools linked to your document sources.

3. JabRef

For users working with BibTeX format (common in computer science and mathematics), JabRef offers direct integration with LibreOffice Writer. It allows you to:

  • Connect a .bib file directly to your Writer document.
  • Insert standard citation keys.
  • Generate formatted reference lists according to predefined style files.
