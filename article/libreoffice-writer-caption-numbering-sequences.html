LibreOffice Writer Caption Numbering Sequences

LibreOffice Writer provides robust tools for automatically numbering image captions, allowing users to select standard sequential formats, integrate multi-level chapter numbering, or define custom numbering sequences. This guide explains the available numbering sequences, chapter-based formatting options, and how to configure automatic captioning for images.

Standard Numbering Formats

When inserting a caption for an image in LibreOffice Writer, the numbering sequence can be customized using the Numbering dropdown in the Caption dialog. The available built-in sequence formats include:

  • Arabic Numerals: 1, 2, 3, 4, ... (Default)
  • Uppercase Roman Numerals: I, II, III, IV, ...
  • Lowercase Roman Numerals: i, ii, iii, iv, ...
  • Uppercase Latin Letters: A, B, C, D, ...
  • Lowercase Latin Letters: a, b, c, d, ...
  • None: Omits numbering entirely, displaying only the category text and description.

Chapter-Based Multi-Level Numbering

LibreOffice Writer allows caption numbers to include the document's chapter or heading level. This creates hierarchical sequences such as Figure 1.1, Figure 1.2, or Figure 2-A.

To configure chapter-based numbering:

  1. Open the Caption dialog (right-click the image and select Insert Caption...).
  2. Click the Options button.
  3. In the Level field, choose how many heading levels to include in the caption number (e.g., Level 1 for main chapters, Level 2 for subheadings).
  4. In the Separator field, define the character placed between the chapter number and the sequence number (such as a period, hyphen, or colon).

Category-Specific Sequence Variables

Numbering sequences are tied to the caption Category. LibreOffice maintains independent numbering sequences for different object types:

  • Figure: Default sequence for photos and graphics.
  • Illustration: Alternative sequence for diagrams and artwork.
  • Table: Sequence for tabular data.
  • Drawing: Sequence for vector shapes and drawn objects.
  • Custom Categories: Users can type any custom category name directly into the Category box. LibreOffice Writer will automatically create and track an independent numbering sequence for that new label.

Configuring Automatic Image Numbering (AutoCaption)

To automatically apply these numbering sequences every time an image is inserted:

  1. Navigate to Tools > Options (or LibreOffice > Preferences on macOS).
  2. Expand the LibreOffice Writer section in the left panel and select AutoCaption.
  3. Under the Add captions automatically when inserting list, check LibreOffice Writer Image.
  4. Configure the default settings for images:
    • Category: Choose or type a category (e.g., Figure).
    • Numbering: Select the desired numbering sequence format (Arabic, Roman, or Alphabetic).
    • Numbering separator: Define characters between the number and caption text.
    • Position: Choose whether captions appear above or below the image.
  5. Click OK to save the configuration.
