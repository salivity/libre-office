LibreOffice Impress Presenter Console Features

LibreOffice Impress includes a built-in Presenter Console that enhances control during slide shows when using multiple displays. This tool provides a dedicated control interface on the presenter's screen while the audience sees only the full-screen presentation on a projector or secondary monitor. This guide covers all the core features, display modes, and management tools available within the LibreOffice Impress Presenter Console.

Key Display Modes

The Presenter Console offers three selectable display modes to fit different presenting styles:

  • Default View: Displays the currently projected slide, a preview of the upcoming slide, the presentation timer, real-world time, and editable speaker notes.
  • Notes View: Enlarges the speaker notes section for improved readability, placing the current slide and upcoming slide previews into smaller side panels.
  • Slide Overview (Sorter) View: Displays a grid of all slides in the deck, allowing the presenter to quickly jump to any slide out of sequence without disrupting the audience display.

Time Management Tools

To help keep presentations on schedule, the console provides several integrated time-tracking features located at the top of the interface:

  • Elapsed Time: Tracks the duration of the current presentation from the moment the slide show starts.
  • Real-World Clock: Displays the current system time to monitor overall scheduling.
  • Timer Controls: Includes options to pause, resume, or reset the elapsed time counter during breaks or practice sessions.

Slide Navigation and Presentation Controls

The bottom toolbar in the Presenter Console provides direct control over the flow of the presentation:

  • Navigation Buttons: Next slide, previous slide, and jump controls to navigate the presentation smoothly.
  • Blank Screen Toggle: Allows the presenter to temporarily turn the audience screen black or white, shifting the audience's focus away from the slides and onto the speaker.
  • Slide Number Indicator: Shows the current slide number relative to the total number of slides (e.g., Slide 4 of 20).
  • Exchange Displays: A dedicated button that swaps the presentation display and the console screen between connected monitors without needing to reconfigure operating system display settings.

Speaker Notes Management

  • Text Size Adjustment: Built-in zoom buttons allow presenters to increase or decrease the font size of their notes directly from the console interface.
  • Private Viewing: Notes remain strictly visible to the presenter, ensuring confidential prompts and detailed cues are hidden from the audience.

Requirements and Configuration

The Presenter Console activates automatically when a multi-monitor setup (extended desktop mode) is detected. It can be configured or enabled manually by navigating to Slide Show > Slide Show Settings within LibreOffice Impress, where users can select which monitor displays the presentation and toggle the console feature on or off.
