Frame Styles for Images and Text in LibreOffice Writer

LibreOffice Writer uses dedicated Frame Styles to control the formatting, positioning, borders, and text-wrapping behavior of floating objects such as images, text boxes, and OLE objects. Instead of manually configuring individual properties for every floating item, Frame Styles allow you to apply consistent layouts across an entire document. Understanding these styles—primarily the Graphics, Frame, and Marginalia presets—ensures precise control over visual and structural document design.

Accessing Frame Styles

Frame Styles are located in the Styles deck of the Sidebar (shortcut: F11 or Ctrl+F11). At the top of the Styles panel, selecting the Frame Styles icon displays all default and custom styles available for framed and floating content.

Primary Frame Styles for Images and Text Boxes

  • Graphics: This is the default frame style automatically applied to inserted images, photographs, and vector graphics. It defines default wrapping behavior, spacing between the graphic and surrounding text, alignment, and default borders.
  • Frame: The standard frame style applied when you insert a text frame (Insert > Frame > Frame). It is designed for floating text blocks, sidebars, and callouts, providing standard internal margins, alignment, and parallel text wrapping.
  • Marginalia: A specialized frame style designed to place floating text or small graphics entirely within the left or right page margins, functioning as side-notes or marginal notes without breaking the flow of the main text body.
  • Formula: The default style applied to embedded Math formula objects, preconfigured to align inline with text (anchored as character).
  • OLE: The default style applied to embedded Object Linking and Embedding (OLE) items, such as spreadsheets or charts created in LibreOffice Calc.
  • Watermark: A background frame style configured with full transparency or light shading, anchored behind body text.

Key Properties Controlled by Frame Styles

When configuring or creating a Frame Style, LibreOffice Writer provides settings that dictate how floating objects behave on the page:

  1. Anchoring: Determines how the frame attaches to the document structure. Options include To Page, To Paragraph, To Character, and As Character (which treats the object as an inline text character).
  2. Text Wrap: Controls how body text flows around the floating box. Settings include None (Wrap Off), Parallel (Page Wrap), Optimal Page Wrap, Before, After, and Through (In Background/Foreground).
  3. Position and Alignment: Dictates horizontal and vertical alignment relative to the paragraph area, page text area, entire page, or character.
  4. Borders and Backgrounds: Defines outer lines, shadow effects, and fill colors or transparency for the frame container.
  5. Spacing: Sets the external padding (distance from surrounding text) and internal padding (distance between the frame edge and its internal content).

Customizing and Applying Frame Styles

To apply a style, select the floating image or frame and double-click the desired style in the Frame Styles list. To modify defaults or create new reusable layouts, right-click any style in the panel and choose Modify or New to adjust wrapping, borders, and positioning parameters.
