How to Edit PDF Documents with LibreOffice Draw

LibreOffice Draw is a powerful, free, open-source tool that lets you modify the content, layout, and structure of existing PDF documents without requiring dedicated, paid software. This step-by-step guide explains how to import a PDF into LibreOffice Draw, edit existing text and images, adjust page layout, and properly export the final result back into standard PDF format.

Step 1: Open the PDF in LibreOffice Draw

  1. Open LibreOffice on your computer.
  2. Click File in the top menu and select Open (or use the shortcut Ctrl + O on Windows/Linux, Cmd + O on Mac).
  3. Navigate to your PDF file, select it, and click Open.
  4. The file will automatically open inside the LibreOffice Draw workspace, where each page is converted into an editable graphical slide.

Step 2: Edit Text Content

Draw converts PDF text into individual text boxes:

  1. Click directly on the text you want to modify to highlight the text frame.
  2. Double-click inside the frame to place the cursor.
  3. Edit, delete, or add text as needed.
  4. Use the Properties panel on the right sidebar to change font family, font size, color, alignment, and spacing.
  5. To add entirely new text, click the Text Box icon (F2) on the toolbar, click and drag on the page, and type your content.

Step 3: Modify, Move, or Insert Images

  1. Move or Resize: Click an existing image to display selection handles. Drag the handles to resize the image or drag the center to reposition it.
  2. Delete: Select the image and press the Delete key on your keyboard.
  3. Replace: Right-click the existing image, select Replace, and choose a new image file from your computer.
  4. Insert New Image: Go to Insert > Image from the top menu, select your file, and position it on the canvas.

Step 4: Manage PDF Pages

The Pages Pane on the left side of the screen displays thumbnails of all pages in your document:

  • Rearrange: Click and drag a page thumbnail up or down to change the page order.
  • Delete: Right-click a page thumbnail and select Delete Page.
  • Add Blank Page: Right-click the Pages Pane and select New Page.

Step 5: Export the Edited PDF

Saving the file normally (Ctrl + S) will save it as an OpenDocument Drawing (.odg) file. To save it back as a PDF:

  1. Click File in the top menu.
  2. Hover over Export As and select Export as PDF... (or click the red Export Directly as PDF icon on the main toolbar).
  3. In the PDF Options dialog, select your desired image compression, quality settings, and security options if needed.
  4. Click Export, choose your destination folder, name the file, and click Save.
