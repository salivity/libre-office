How to Use Dimension Lines in LibreOffice Draw

LibreOffice Draw provides built-in dimensioning tools and scaling capabilities suitable for creating 2D architectural plans, elevations, and technical layouts. This guide covers how to configure the drawing scale, place and snap dimension lines to objects, format measurement units, and organize architectural dimensions using layers.

Setting Up Document Scale and Units

Before drawing dimension lines, you must set the drawing scale so that measurements accurately represent real-world architectural dimensions.

  1. Navigate to Tools > Options (or LibreOffice > Preferences on macOS).
  2. Expand LibreOffice Draw in the left sidebar and select General.
  3. Under the Scale section, choose an appropriate architectural scale (such as 1:50 or 1:100).
  4. Set the default Unit of measurement to your preferred standard, such as meters, centimeters, or feet/inches.
  5. Click OK to apply the changes.

To ensure alignment accuracy, enable snapping by going to View > Snap Guides and ensuring Snap to Object Points and Snap to Grid are active.

Inserting Dimension Lines

  1. Locate the Lines and Arrows dropdown on the main Drawing toolbar.
  2. Select the Dimension Line tool.
  3. Click and hold on the starting point of the object or wall you want to measure.
  4. Drag the cursor to the endpoint of the object and release the mouse button.
  5. Drag perpendicular to the measured line to set the offset distance for the dimension line and extension guides, then click to place it.

The dimension line will automatically compute and display the scaled measurement between the two points.

Customizing Dimension Line Properties

You can adjust the appearance, text format, and offset markers to conform to architectural drafting standards:

  1. Right-click the placed dimension line and select Dimensions... from the context menu.
  2. Configure the following key settings in the dialog:
    • Line Distance: Sets the distance between the measurement line and the object.
    • Guide Line Overhang: Controls how far the extension lines extend past the dimension line.
    • Guide Line Distance: Sets the gap between the object boundary and the start of the extension line.
    • Unit: Check or uncheck Show unit of measurement depending on standard blueprint formatting (many architectural plans omit the unit label if defined in a title block).
    • Text Position: Choose whether the dimension text appears centered inside the line, above the line, or outside the guides.
    • Decimal Places: Adjust precision based on your tolerance requirements.
  3. Click OK to update the line.

To adjust styling such as line weight, arrowheads, or ticks (often preferred in architectural drafting over standard arrows), select the dimension line and use the Properties sidebar on the right to modify the line style and end markers.

Organizing Dimensions with Layers

For professional drafting workflow, keep dimensions separate from geometry:

  1. Look at the bottom of the Draw workspace to see the Layer Tabs (Layout, Controls, Dimension Lines).
  2. Draw directly on the default Dimension Lines layer, or right-click a layer tab and choose Insert Layer to create a custom one.
  3. Locking or hiding the dimension layer allows you to edit architectural geometry without accidentally moving or deleting measurement callouts.
