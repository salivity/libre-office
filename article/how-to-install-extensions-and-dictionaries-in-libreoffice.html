How to Install Extensions and Dictionaries in LibreOffice

LibreOffice supports a wide range of third-party add-ons to boost productivity, customize formatting, and expand language support. This guide provides a straightforward, step-by-step walkthrough on how to download and install both third-party extensions and spelling dictionaries using LibreOffice's built-in Extension Manager.

Step 1: Download the Extension or Dictionary File

Most LibreOffice extensions and dictionaries are distributed as files with the .oxt extension.

  1. Visit the official LibreOffice Extensions & Templates Repository or a trusted third-party developer's website.
  2. Search for the desired extension or dictionary package.
  3. Download the .oxt file to your computer and note the download location.

Step 2: Open the Extension Manager

You can install downloaded packages directly inside any LibreOffice application (Writer, Calc, Impress, etc.):

  1. Launch LibreOffice.
  2. In the top menu bar, click on Tools.
  3. Select Extension Manager from the drop-down menu (or press Ctrl + Alt + E on Windows/Linux, Cmd + Option + E on macOS).

Step 3: Install the .oxt File

  1. In the Extension Manager window, click the Add... button located at the bottom.
  2. A file browser window will appear. Navigate to the folder containing your downloaded .oxt file.
  3. Select the file and click Open.
  4. If prompted with an extension license agreement, scroll to the bottom and click Accept.
  5. Choose whether to install the extension For all users (requires administrator privileges) or Only for me.

Step 4: Restart LibreOffice

After the installation completes, the extension or dictionary will appear in the Extension Manager list.

  1. Click Close in the Extension Manager window.
  2. A prompt may ask you to restart LibreOffice. Choose Restart Now to apply the changes.
  3. Once restarted, the new features, toolbars, or dictionary languages will be active.

Activating a Newly Installed Dictionary

If you installed a dictionary or spell-check package, verify that the language is enabled:

  1. Go to Tools > Options (or LibreOffice > Preferences on macOS).
  2. Expand Language Settings on the left menu and select Languages.
  3. Under Default Languages for Documents, choose your newly installed language for Western (or other appropriate script type).
  4. Click Writing Aids under Language Settings to ensure the new spell-checker module is checked.
  5. Click Apply and OK.

Managing and Removing Extensions

To update, disable, or remove an installed add-on at any time:

  1. Go to Tools > Extension Manager.
  2. Select the extension from the list.
  3. Click Disable to temporarily turn it off, Remove to delete it completely, or Check for Updates to look for newer versions online.
