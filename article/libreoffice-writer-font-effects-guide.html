LibreOffice Writer Font Effects Guide

LibreOffice Writer offers a built-in collection of typographic font effects that allow users to customize the visual appearance of their text beyond standard bold, italic, and underline styling. Accessible through the Character formatting menu, these features include relief options like embossing and engraving, outline and shadow effects, advanced lines, and emphasis marks to enhance document design.

How to Access Font Effects in LibreOffice Writer

To access font effects for selected text:

  1. Highlight the text you want to modify.
  2. Go to Format in the top menu and select Character (or right-click the text and choose Character).
  3. Click on the Font Effects tab in the Character dialog window.

Supported Font Effects

LibreOffice Writer provides several categories of font effects:

1. Relief Effects (Embossing and Engraving)

The Relief drop-down menu creates a three-dimensional look on text:

  • Embossed: Makes the text appear raised above the background surface.
  • Engraved: Makes the text appear pressed or carved into the background surface.

2. Outline and Shadow

These options can be applied independently or together:

  • Outline: Converts characters into hollow outlines, displaying only the border of each letter.
  • Shadow: Adds a soft, offset drop shadow behind the text to create depth.

3. Overlining, Underlining, and Strikethrough

Writer allows detailed customization for line-based decorations:

  • Overlining & Underlining: You can select from single, double, dotted, dashed, or wave lines, and assign a custom line color independent of the text color.
  • Strikethrough: Options include single, double, bold, or specialized styles (such as slashes or "X" marks over characters).
  • Individual Words Only: A checkbox allows you to apply underlines, overlines, or strikethroughs exclusively to words while leaving the spaces between them blank.

4. Font Color and Transparency

  • Font Color: Choose any color from standard palettes or define custom RGB/HEX values.
  • Transparency: Set a percentage value to make text semi-transparent, allowing background elements or colors to show through.

5. Emphasis Marks

Emphasis marks place symbols (such as dots, circles, or accents) above or below selected characters. This feature is commonly used in East Asian typography but is available for any text.

Related Text Positioning Effects

Additional character transformations are available in the Position tab of the Character dialog:

  • Superscript and Subscript: Raise or lower characters relative to the baseline with custom scaling.
  • Rotation / Scaling: Rotate text by 90 or 270 degrees, or adjust character width scaling horizontally.
  • Kerning and Character Spacing: Expand or condense the spacing between individual characters.
