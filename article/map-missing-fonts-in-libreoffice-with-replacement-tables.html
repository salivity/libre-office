Map Missing Fonts in LibreOffice with Replacement Tables

LibreOffice provides a built-in Font Replacement Table feature that enables users to automatically substitute missing, proprietary, or unavailable fonts with installed alternatives without altering the original document formatting. This article explains how the font replacement table works in LibreOffice, how to configure custom mappings for missing fonts, and the most common metric-compatible font substitutions to preserve document layouts.

Understanding the Font Replacement Table

When you open a document created on another operating system or computer, it may reference fonts not installed on your system. By default, LibreOffice attempts an automatic fallback, but this can lead to text overflow, misaligned tables, and unwanted line breaks. The Font Replacement Table allows you to explicitly define which installed font should replace a missing font, ensuring visual consistency across platforms.

How to Access and Configure Font Replacement in LibreOffice

To set up font substitution rules, follow these steps:

  1. Open Options:
    • Windows/Linux: Go to Tools > Options.
    • macOS: Go to LibreOffice > Preferences.
  2. Navigate to Fonts Settings: In the left sidebar, expand the LibreOffice section and select Fonts.
  3. Enable Replacements: Check the box labeled Apply replacement table.
  4. Create a Mapping Rule:
    • In the Font dropdown box, type or select the name of the missing font (e.g., Calibri).
    • In the Replace with dropdown box, select the installed font you want to use as the substitute (e.g., Carlito).
    • Click the green checkmark icon to add the rule to the table.
  5. Set Replacement Conditions:
    • Always: Replaces the font both on-screen and when exporting/printing.
    • Screen only: Replaces the font only for display rendering while keeping the original font metrics targeted for printing devices.
  6. Save Changes: Click Apply and then OK.

Recommended Font Mappings for Missing Fonts

To maintain page layout fidelity—known as metric compatibility—use these standard pairings when mapping common proprietary Microsoft fonts to free, open-source alternatives:

Missing / Target Font Recommended Replacement Font Notes
Calibri Carlito Metric-compatible modern sans-serif substitute
Cambria Caladea Metric-compatible modern serif substitute
Arial Liberation Sans or Arimo Identical character widths and spacing
Times New Roman Liberation Serif or Tinos Identical character widths and spacing
Courier New Liberation Mono or Cousine Identical fixed-width character spacing
Segoe UI Selawik or Open Sans UI and document standard substitution
Tahoma / Verdana DejaVu Sans Similar broad x-height and readability

Additional Tips for Font Mapping

  • Font Names Must Match Exactly: When typing the name of an uninstalled font in the Font field, ensure the spelling matches the exact font family name stored in the document.
  • Document Portability: Font replacements configured via the table are application-level settings. They affect how LibreOffice renders files on your local machine and do not permanently rewrite the font tags inside the document file itself unless you manually change the styling.
  • Font Embedding Alternative: If sharing documents across systems where you cannot control user settings, consider embedding the fonts via File > Properties > Font tab by selecting Embed fonts in the document.
