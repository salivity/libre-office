Create a Table of Figures in LibreOffice Writer

Creating a table of figures in LibreOffice Writer allows you to automatically generate a neat, organized list of all images, diagrams, and illustrations present in your document. By utilizing Writer's built-in captioning system, you can ensure that figure numbers, titles, and corresponding page references update dynamically whenever changes are made to your layout.

Step 1: Add Captions to Your Illustrations

To include images in an automated list, each graphic must first be assigned a proper caption.

  1. Right-click the image or illustration in your document.
  2. Select Insert Caption... from the context menu.
  3. In the Category dropdown, select Figure (or Illustration).
  4. In the Caption field, type the description or title of your image.
  5. Choose your preferred numbering style and caption position (usually Below).
  6. Click OK.

Repeat this process for every illustration you want to appear in the table.

Step 2: Insert the Table of Figures

Once all necessary images have captions, you can place the table of figures anywhere in the document.

  1. Click where you want the table of figures to appear (such as at the beginning or end of your document).
  2. Go to the top menu and select Insert > Table of Contents and Index > Table of Contents, Index or Bibliography....
  3. In the dialog box that appears, navigate to the Type tab.
  4. Set the Type dropdown to Table of Figures.
  5. Under the Create from section, ensure the Category matches the label you used for your captions (e.g., Figure).
  6. Choose how you want the entries displayed under the Display option (typically Caption Text or References).
  7. Click OK to generate the table.

Step 3: Update the Table of Figures

The table of figures does not automatically refresh in real time as you edit. If you add, delete, or rearrange illustrations:

  1. Right-click anywhere inside the generated table of figures.
  2. Select Update Index from the context menu.

LibreOffice Writer will immediately scan the document and adjust all figure names, numbers, and page references accordingly.
