How to Convert Raster to Vector in LibreOffice Draw

Converting raster photographs into editable vector polygons in LibreOffice Draw is a straightforward process using the software's built-in bitmap tracing tool. This guide outlines how to import a raster image (such as a PNG or JPEG), apply the polygon conversion tool, configure detail settings to control vector complexity, and ungroup the generated shapes for individual node and color editing.

1. Import the Raster Photograph

Launch LibreOffice Draw and open a new or existing drawing canvas. To import your image, go to the top menu and select Insert > Image..., or simply drag and drop your raster image file directly onto the workspace. Click on the image once to ensure it is selected.

2. Open the Conversion Dialog

With the image selected, open the conversion tool through either of these methods:

  • Go to the top menu and select Shape > Convert > To Polygon.
  • Alternatively, right-click the image directly on the canvas and choose Convert > To Polygon.

3. Adjust the Vectorization Settings

The "Convert to Polygon" dialog window will appear, allowing you to fine-tune how the raster image is converted into vector shapes:

  • Number of colors: Defines how many distinct color regions will be created. A lower number (e.g., 8–16) creates a simpler, posterized vector graphic, while a higher number creates more detailed paths at the expense of performance.
  • Point reduction: Smooths the edges of the generated polygons. Increasing this value removes minor imperfections and reduces the total node count.
  • Fill holes: Check this option to ensure internal gaps within color regions are filled with solid vector shapes rather than transparent voids.
  • Tile size: Adjusts the pixel sample size used to calculate boundaries.

Click the Preview button to view the result directly in the dialog window. Once you are satisfied with the balance of detail and shape simplicity, click OK.

4. Ungroup the Converted Vector Polygons

After conversion, LibreOffice Draw combines all generated vector paths into a single grouped object. To edit individual sections:

  1. Select the converted object.
  2. Right-click the object and select Group > Ungroup (or press Ctrl + Shift + Alt + G).
  3. Click outside the graphic to deselect everything, then click on any individual polygon to modify its fill color, border, size, or position.

5. Edit Polygon Nodes and Paths

To modify the shape of specific polygons, select an individual shape and press F8 (or click the Points icon on the Standard toolbar) to activate node editing. You can now drag individual anchor points, delete excess nodes, or adjust curve handles to refine the vector artwork.

Once your edits are complete, you can save your file in the native Draw format (.odg) or export it as a vector file such as SVG or PDF via File > Export....
