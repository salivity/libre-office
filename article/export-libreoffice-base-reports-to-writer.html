Export LibreOffice Base Reports to Writer

LibreOffice Base allows users to generate structured reports from queries and tables, but many users struggle to convert these outputs into editable formats. When generated, reports often default to a read-only view or standard print layout. This guide explains how to generate, unlock, and export your LibreOffice Base reports directly into fully editable LibreOffice Writer (.odt) documents.

Step 1: Open and Run Your Report

  1. Open your .odb database file in LibreOffice Base.
  2. In the left-hand database panel, click on the Reports section.
  3. Double-click the report you wish to export to execute it.
  4. LibreOffice Base will process the data and display the generated report in a new window.

Step 2: Enable Editing Mode

By default, generated reports open as static, read-only documents to preserve the layout.

  1. Look at the top toolbar in the newly opened report window.
  2. Click the Edit Document icon (represented by a pencil and document) or press Ctrl + Shift + M.
  3. If the button is disabled or unavailable, proceed directly to saving the file as a standalone document.

Step 3: Save the Report as an Editable Writer Document

To make the report permanently editable independent of the Base file:

  1. In the report window, go to the top menu and select File > Save As....
  2. Choose your preferred destination folder.
  3. In the Save as type dropdown menu, ensure ODF Text Document (.odt) is selected.
  4. Name your file and click Save.

Step 4: Work with the Document in LibreOffice Writer

  1. Close the LibreOffice Base report viewer.
  2. Navigate to where you saved the .odt file and open it.
  3. The document will now open directly in LibreOffice Writer, giving you full access to modify text, adjust tables, change fonts, and add additional content.

Alternative: Exporting Query Data Directly to Writer

If you only need the raw data in an editable table format without the predefined report layout:

  1. In LibreOffice Base, open the Tables or Queries tab.
  2. Drag and drop the desired table or query directly into a blank LibreOffice Writer document.
  3. In the popup dialog, choose Insert data as Table and select the columns to import.
