LibreOffice Documentation and User Guides

The LibreOffice community actively maintains an extensive ecosystem of free documentation and learning resources to support users, administrators, and developers. These resources range from comprehensive, downloadable user manuals for each individual component of the office suite to interactive online help systems, community wikis, and peer-support platforms. Together, they provide continuous, up-to-date guidance for both beginner and advanced users across all supported operating systems.

Official User Guides

The LibreOffice Documentation Team produces full-length, modular user guides for each major release. These guides are available for free download in both PDF and editable OpenDocument Format (ODT), with printed copies available for purchase. The core library includes:

  • Getting Started Guide: An introductory manual covering general settings, common features, user interface customization, and basic operations across the suite.
  • Writer Guide: Detailed instructions for word processing, formatting, desktop publishing, mail merges, and document collaboration.
  • Calc Guide: Guidance on spreadsheets, data analysis, formulas, functions, charting, and pivot tables.
  • Impress Guide: Instructions for creating slides, transitions, animations, multimedia presentations, and speaker notes.
  • Draw Guide: Manual for vector graphics, technical drawing, diagramming, and flowchart creation.
  • Base Guide: Comprehensive reference for database creation, SQL querying, form building, and report generation.
  • Math Guide: Instructions for creating and editing mathematical formulas and equations.

LibreOffice Help System

LibreOffice provides a multi-tiered help system integrated directly into the application and mirrored on the web:

  • Offline Help: A downloadable package that integrates directly with the installed software, allowing users to press F1 or click contextual help buttons to access offline reference articles.
  • Online Help: A searchable, web-based version of the help documentation that is continuously updated with the latest interface changes, shortcut keys, and function definitions.

The LibreOffice Wiki

The official LibreOffice Wiki serves as a dynamic collaborative space containing technical documentation, planning notes, and specialized tutorials. Key sections include:

  • Tutorials and How-Tos: Step-by-step guides for specific tasks, advanced formatting, and macro scripting (using LibreOffice Basic, Python, and other languages).
  • Release Notes: Detailed overviews of changes, newly added features, deprecated functions, and compatibility updates for every major and minor version.
  • Developer and QA Documentation: Resources for contributing code, building from source, testing bug fixes, and understanding the LibreOffice API.

Community Support and Knowledge Base

For interactive and troubleshooting help, the community operates several dedicated channels:

  • Ask LibreOffice: A question-and-answer platform where users can search for previously solved issues or submit new queries to be answered by community experts.
  • Mailing Lists: Dedicated email lists for user support, documentation contributors, localization teams, and development discussions.
  • Chat Channels: Real-time IRC and Matrix channels where users and contributors can ask questions and collaborate directly with the global community.
