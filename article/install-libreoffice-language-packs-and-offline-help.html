Install LibreOffice Language Packs and Offline Help

This guide provides step-by-step instructions for downloading, installing, and configuring additional user interface languages and offline help documentation in LibreOffice. Whether you are using Windows, macOS, or Linux, adding these components allows you to use the office suite in your preferred language and access comprehensive documentation without an active internet connection.

Step 1: Check Your LibreOffice Version

To ensure compatibility, the language pack and offline help installer must match your installed LibreOffice version and system architecture (32-bit or 64-bit).

  1. Open any LibreOffice application (such as Writer or Calc).
  2. Go to Help > About LibreOffice (on macOS, LibreOffice > About LibreOffice).
  3. Note the exact version number (e.g., 7.6.4) and architecture (e.g., x86_64).

Step 2: Download and Install Components

On Windows

  1. Open your web browser and navigate to the official LibreOffice download page.
  2. Under your current version's download section, look for the Need another language? or Supplementary Downloads section.
  3. Download the Translated User Interface installer and the Help for offline use installer for your specific language.
  4. Close LibreOffice completely (including the Quickstarter in the system tray).
  5. Run the downloaded .msi installers one by one and follow the on-screen prompts to complete the installation.

On macOS

  1. Navigate to the official LibreOffice download page and find the downloads for macOS corresponding to your chip type (Intel or Apple Silicon).
  2. Download both the Language Pack (.dmg) and the Offline Help (.dmg) for your target language.
  3. Open the downloaded Language Pack disk image and double-click the installer icon. Follow the instructions to patch your existing LibreOffice installation.
  4. Open the Offline Help disk image and run its installer to complete the setup.

On Linux

Most Linux distributions provide language packs and help files directly through their package managers. Open a terminal and run the appropriate command for your distribution (replace [lang-code] with your language code, such as es for Spanish, fr for French, or de for German):

  • Debian / Ubuntu / Linux Mint:

    sudo apt update
sudo apt install libreoffice-l10n-[lang-code] libreoffice-help-[lang-code]

  • Fedora / RHEL:

    sudo dnf install libreoffice-langpack-[lang-code] libreoffice-help-[lang-code]

  • Arch Linux:

    sudo pacman -S libreoffice-fresh-[lang-code]

Step 3: Activate the Language in LibreOffice

After installing the packages, you must enable them inside LibreOffice settings.

  1. Launch LibreOffice.
  2. Go to Tools > Options (on macOS: LibreOffice > Preferences).
  3. In the left panel, expand Language Settings and select Languages.
  4. Configure your preferences:
    • User Interface: Select your newly installed language to change the menu and button text.
    • Locale setting: Set your regional formats (dates, currency, measurement units).
    • Default Languages for Documents: Set your preferred language for spell-checking and grammar tools.
  5. Click Apply and then OK.
  6. Restart LibreOffice for the interface changes to take full effect.

Step 4: Verify Offline Help

  1. Open LibreOffice Writer or Calc.
  2. Press F1 or go to Help > LibreOffice Help.
  3. The documentation should open immediately in your default web browser locally from your hard drive, functioning without an active internet connection.
