How to Split and Merge Tables in LibreOffice Writer

LibreOffice Writer provides built-in tools that allow users to manage document layouts by splitting large tables into separate sections, combining adjacent tables into a single entity, and modifying individual cells. This guide outlines the specific tools, menu commands, and settings available for splitting and merging both entire tables and individual cells within LibreOffice Writer.

Splitting Tables

The Split Table tool is used to divide a single table horizontally into two separate tables at a specified row.

How to Access the Tool

  1. Place the text cursor in any cell of the row where you want the second table to begin.
  2. Go to the top menu and select Table > Split Table..., or right-click the cell and select Split Table... from the context menu.

Configuration Options

When the Split Table dialog box appears, you can choose how to handle table headers for the newly created bottom table:

  • Copy heading: Duplicates the header row(s) from the original table to the new table.
  • Custom heading (apply style): Creates a blank header row formatted with the default heading style.
  • Custom heading (no style): Creates a blank row without special formatting.
  • No heading: Splits the table directly without inserting any header row into the second table.

Merging Tables

LibreOffice Writer allows you to combine two consecutive tables into one.

Methods for Merging Tables

  1. The Merge Table Command:

    • Ensure there is no text or blank paragraph between the two tables.
    • Place the cursor anywhere in the second table.
    • Navigate to Table > Merge Table in the top menu. (This option only becomes active when the cursor is in a table immediately preceded by another table).

  2. Keyboard Deletion Method:

    • If there is an empty paragraph break separating two tables, place your cursor in the empty paragraph between them.
    • Press the Delete key (or press Backspace at the start of the second table).
    • Once the separating space is removed, the tables will automatically join into a single table.

Note: For the best visual result, ensure both tables have the same number of columns before merging.

Splitting and Merging Cells

In addition to splitting and merging entire tables, LibreOffice Writer includes dedicated tools for cell-level operations.

Merge Cells Tool

  • Function: Combines two or more selected adjacent cells into a single larger cell.
  • Access: Highlight the target cells, then go to Table > Merge Cells, click the Merge Cells icon on the Table Toolbar, or right-click and select Merge Cells.

Split Cells Tool

  • Function: Divides a single cell or a group of selected cells into multiple rows or columns.
  • Access: Select the cell(s), then navigate to Table > Split Cells... or click the Split Cells icon on the Table Toolbar.
  • Options Available:
    • Split cell into: Set the exact number of segments to create.
    • Direction: Choose Horizontally (divides into rows) or Vertically (divides into columns).
    • Into equal proportions: Ensures all newly split cells have identical widths or heights.

The Table Toolbar

When your cursor is inside any table, the Table Toolbar automatically appears (usually docked at the bottom of the workspace). This toolbar provides one-click access to:

  • The Merge Cells icon
  • The Split Cells icon
  • Table formatting and alignment controls
