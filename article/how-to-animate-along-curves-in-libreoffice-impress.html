How to Animate Along Curves in LibreOffice Impress

LibreOffice Impress includes built-in Motion Path animation tools that allow users to move objects, shapes, and graphics along custom trajectories, including smooth curves and freeform lines. By combining the Custom Animation panel with vector point-editing tools, you can create, modify, and fine-tune custom curved pathways to control the exact motion of any graphical element across a slide.

Accessing Motion Path Tools

To apply a custom curve animation to a graphic:

  1. Select the graphic or shape on the slide.
  2. Open the Sidebar and click on the Animation icon (the star icon) to open the Custom Animation panel.
  3. Click the Add (+) button (or select Add Effect).
  4. In the Category dropdown menu, select Motion Paths.

Built-In Custom Curve Options

Under the Motion Paths category, LibreOffice Impress provides several tools specifically designed for user-defined curved trajectories:

  • Curve: Allows you to define smooth, curving paths by clicking to place individual curve nodes. Double-click to complete the path.
  • Freeform Line: Lets you draw a continuous, hand-drawn path by holding down the mouse button and drawing directly on the slide.
  • Polygon: Enables multi-point, segmented paths with sharp angles between defined points.

Editing Custom Paths with the Points Tool

Once a motion path is generated, it exists as a vector line that can be customized with precision:

  1. Select the motion path on the slide canvas.
  2. Press F8 or click the Points icon on the standard toolbar to activate node-editing mode.
  3. Click and drag existing nodes (points) to change the path's geometry.
  4. Adjust the Bezier control handles attached to each point to modify the smoothness and intensity of the curves.
  5. Use the Edit Points toolbar to insert new points, delete unwanted points, or convert sharp corners into smooth transitions.

Fine-Tuning Motion Settings

After shaping the custom curve, configure the movement behavior in the Custom Animation sidebar:

  • Duration: Set the time (in seconds) it takes for the graphic to travel along the curve.
  • Smooth Start / Smooth End: Enable acceleration and deceleration for more natural motion.
  • Direction: Invert the path direction via Effect Options if the graphic needs to travel in reverse.
  • Trigger and Delay: Define whether the animation starts on a mouse click, automatically with the previous animation, or after a specific delay.
