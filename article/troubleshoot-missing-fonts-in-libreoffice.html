Troubleshoot Missing Fonts in LibreOffice

LibreOffice automatically substitutes fonts when a document requires a typeface not installed on your operating system, which often alters document layout, spacing, and formatting. This guide provides a straightforward method to identify substituted fonts, configure LibreOffice's built-in font replacement table, install the required fonts on your system, and embed fonts directly into files to prevent future display issues across different devices.

1. Identify Substituted Fonts

LibreOffice indicates missing fonts directly within its user interface:

  1. Open the document and click on the text in question.
  2. Look at the Font Name box on the Formatting toolbar.
  3. If the font name appears in italics, the font is not installed on your system. LibreOffice is using an alternative fallback font to render the text.

2. Install the Missing Fonts on Your Operating System

The most effective fix is installing the original font files (.ttf or .otf) directly to your operating system.

  • Windows: Download the font, right-click the font file, and select Install (or Install for all users).
  • Linux: Copy the font files to ~/.local/share/fonts/ (user-level) or /usr/share/fonts/ (system-wide), then run fc-cache -f -v in the terminal.
  • macOS: Double-click the downloaded font file and click Install Font in the Font Book window.

Restart LibreOffice after installation so the software recognizes the newly added fonts.

3. Configure the Font Replacement Table

If you do not have the original font, you can explicitly tell LibreOffice which installed font to use as a substitute instead of letting the software guess.

  1. Navigate to Tools > Options (on macOS: LibreOffice > Preferences).
  2. Expand the LibreOffice section on the left and select Fonts.
  3. Check the box labeled Apply replacement table.
  4. In the Font field, type or select the name of the missing font.
  5. In the Replace with field, select an installed font that closely matches the original.
  6. Click the Checkmark (Add) button to create the rule.
  7. Select Always or Screen only based on your display and printing preferences.
  8. Click OK to apply the changes.

4. Embed Fonts in the Document

To ensure that recipients on other computers see the exact same fonts without installing them manually, embed the fonts directly into your LibreOffice file.

  1. Go to File > Properties.
  2. Select the Font tab.
  3. Check the box for Embed fonts in the document.
  4. (Optional) Check Only embed fonts that are used in the document to reduce file size.
  5. Click OK and save your document.

Note: Fonts with restricted licensing permissions cannot be embedded.

5. Export as PDF for Consistent Distribution

If the recipient only needs to read or print the document without editing it, export the file as a PDF. Navigate to File > Export As > Export as PDF, ensure that standard PDF rendering is selected, and click Export. This embeds the visual representations of all glyphs, ensuring identical display across any device.
