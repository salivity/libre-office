Install Medical and Legal Dictionaries in LibreOffice

LibreOffice allows users to expand its default spell-checking capabilities by integrating specialized vocabulary databases, such as medical, legal, and technical lexicons. This guide provides a straightforward walkthrough on how to source, install, and manage specialized dictionaries in LibreOffice using extension packages and custom word lists, ensuring accurate spell-checking for domain-specific terminology.

Method 1: Installing Dictionaries as Extensions (.OXT)

The easiest way to add comprehensive medical or legal dictionaries is by using packaged LibreOffice extension files (.oxt).

  1. Download the Lexicon Extension: Obtain a trusted .oxt dictionary package (such as OpenMedSpel for medical terms or specific legal lexicon packs) from the official LibreOffice Extensions repository or a verified provider.
  2. Open the Extension Manager: Launch LibreOffice, click on Tools in the top menu, and select Extension Manager (or press Ctrl + Alt + E).
  3. Add the Extension: Click the Add button, navigate to the downloaded .oxt file on your computer, select it, and click Open.
  4. Accept License Terms: If prompted, scroll through and accept the extension’s license agreement.
  5. Restart LibreOffice: Close and restart LibreOffice to apply the new dictionary across Writer, Calc, and other suite applications.

Method 2: Adding Custom Word Lists (.DIC) Manually

If your specialized dictionary is provided as a plain text word list or a .dic file rather than an extension, you can import it as a user-defined dictionary.

  1. Access Writing Aids: Open LibreOffice Writer, go to Tools > Options (on macOS, LibreOffice > Preferences).
  2. Navigate to Language Settings: Expand Language Settings in the left sidebar and select Writing Aids.
  3. Create a New Dictionary: Under the User-defined dictionaries section, click the New... button.
  4. Name and Configure:
    • Enter a descriptive name (e.g., "Medical_Terms").
    • Select the target language (e.g., English (USA)) or leave it set to [All] to apply across all languages.
    • Click OK.
  5. Add Words: Select your newly created dictionary from the list, click Edit, and manually add words or paste terms directly into the list. Click Close when finished.

Managing and Configuring Installed Dictionaries

Once installed, ensure your specialized lexicons are active and properly prioritized.

  • Enable or Disable Lexicons: Go to Tools > Options > Language Settings > Writing Aids. Check or uncheck the boxes next to your specialized dictionaries under User-defined dictionaries to toggle them on or off.
  • Update or Remove Extensions: Open Tools > Extension Manager. Select the dictionary extension to check for updates, temporarily disable it, or click Remove to uninstall it completely.
  • Match Document Language: Specialized dictionaries only trigger if the text matches the dictionary's assigned language. Verify your document language by checking the status bar at the bottom of LibreOffice Writer or navigating to Tools > Language > For all Text.
