Restart Numbering Options in LibreOffice Writer

Managing list sequences in LibreOffice Writer allows you to control document flow by restarting numbered lists, choosing custom starting values, or reconnecting interrupted sequences. This guide covers the various built-in options and methods available for restarting list numbering within LibreOffice Writer documents.

1. Instant Restart to Default (Start at 1)

The quickest way to restart a list is through the context menu:

  • Place your cursor on the list item where the numbering should reset.
  • Right-click the item and select Restart Numbering.
  • The selected line will automatically reset to the initial number (typically 1 or the list's default starting character).

2. Setting a Custom Starting Value

If you need a list to begin at a specific number other than 1 (for example, continuing a list from a previous document or section), use paragraph properties:

  1. Right-click the list item and choose Paragraph > Paragraph... (or go to Format > Paragraph from the top menu).
  2. Navigate to the Outline & List (or Outline & Numbering) tab.
  3. In the Numbering section, check the box for Restart at this paragraph.
  4. Check the Start with checkbox and enter the desired integer into the value field.
  5. Click OK to apply the custom starting number.

3. Continuing Previous Numbering

If a list was restarted by mistake or was split by intervening text and needs to reconnect to the preceding sequence:

  • Right-click the first item of the separated list.
  • Select Continue previous numbering to automatically synchronize it with the count of the previous list.

4. Multi-Level and Style-Based Restart Options

For complex documents using custom list styles or multi-level outlines:

  • Open the Bullets and Numbering dialog by selecting Format > Bullets and Numbering....
  • In the Customize tab, you can set the Start at value for each individual outline level.
  • When using dedicated List Styles via the Styles deck (F11), each style maintains independent sequence settings, preventing automatic merging with other list types across the document.
