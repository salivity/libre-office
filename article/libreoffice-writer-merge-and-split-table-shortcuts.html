LibreOffice Writer Merge and Split Table Shortcuts

LibreOffice Writer provides flexible options for adjusting table layouts, including splitting and merging table cells. While LibreOffice does not provide pre-assigned default shortcut key combinations specifically for merging and splitting cells, you can quickly execute these functions using menu accelerator keys, the contextual Table toolbar, or by assigning your own custom keyboard shortcuts.

Standard Keyboard Access (Accelerator Keys)

You can perform merge and split actions using standard keyboard sequences without reaching for the mouse:

  • Merge Cells:

    1. Select the adjacent cells you want to combine.
    2. Press Alt + A to open the Table menu.
    3. Press M to activate Merge Cells. (Alternative: Press Shift + F10 or the Menu key to open the context menu, then press M.)

  • Split Cells:

    1. Place the cursor in the cell (or select multiple cells) you want to divide.
    2. Press Alt + A to open the Table menu.
    3. Press S followed by C to select Split Cells.
    4. In the pop-up dialog, choose your desired number of splits and orientation (horizontal or vertical), then press Enter.

How to Assign Custom Keyboard Shortcuts

To create true, single-combination keyboard shortcuts (such as Ctrl + Shift + M for Merge and Ctrl + Shift + S for Split), configure them through the Customize menu:

  1. Click Tools in the top menu bar and select Customize...
  2. In the Customize window, switch to the Keyboard tab.
  3. In the top-right corner, ensure Writer is selected so the shortcut applies across all text documents.
  4. Under the Shortcut Keys list at the top, scroll and select your desired key combination (for example, Ctrl + Alt + M).
  5. Under the Category section at the bottom-left, select Table.
  6. Under the Function section in the middle, select Merge Cells (or Split Cells).
  7. Click the Assign button on the right side to link the function to the selected key combination.
  8. Repeat the process for Split Cells using another key combination (such as Ctrl + Alt + S).
  9. Click OK to save the changes.

Once configured, your custom shortcuts will instantly merge or open the split dialogue whenever your cursor or selection is inside a table.
