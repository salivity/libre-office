LibreOffice Calc Shortcuts for Faster Navigation

Mastering keyboard shortcuts in LibreOffice Calc eliminates the need to constantly switch between your keyboard and mouse, dramatically improving your data entry and analysis speed. This guide covers the essential shortcuts for jumping across large datasets, switching between sheets, and navigating cell grids with precision.

Basic Cell and Screen Movement

  • Arrow Keys: Move one cell up, down, left, or right.
  • Page Down / Page Up: Move the view down or up by one full screen.
  • Alt + Page Down / Alt + Page Up: Scroll the view right or left by one full screen.
  • Tab: Move one cell to the right.
  • Shift + Tab: Move one cell to the left.
  • Enter: Move down to the cell below (or the start of the next row if entering data in a range).
  • Shift + Enter: Move up to the cell above.

Large Data Block Navigation

  • Ctrl + Arrow Keys: Jump directly to the edge of the current continuous data region in the direction of the arrow.
  • Home: Jump to the first column (Column A) of the active row.
  • Ctrl + Home: Jump directly to the very first cell of the worksheet (A1).
  • Ctrl + End: Jump to the bottom-right cell of the used data range on the current sheet.

Sheet and Document Navigation

  • Ctrl + Page Down: Move to the next sheet tab to the right.
  • Ctrl + Page Up: Move to the previous sheet tab to the left.
  • Ctrl + Tab: Switch to the next open LibreOffice document window.
  • Ctrl + Shift + Tab: Switch to the previous open LibreOffice document window.

Fast Selection While Navigating

  • Shift + Arrow Keys: Expand or shrink the current cell selection by one cell.
  • Ctrl + Shift + Arrow Keys: Extend the selection to the edge of the current continuous data block.
  • Shift + Space: Select the entire current row.
  • Ctrl + Space: Select the entire current column.
  • Ctrl + A: Select all cells in the current data region; pressing it a second time selects the entire worksheet.

Direct Navigation Tools

  • F5: Open or close the Navigator sidebar to quickly jump to specific ranges, named areas, or sheet objects.
  • Ctrl + G (or typing directly into the Name Box): Move focus to the Name Box to type a specific cell reference (e.g., D250) and press Enter to jump there instantly.
  • Ctrl + F: Open the Find toolbar to search and jump directly to cells containing specific text or numbers.
