How to Export Transparent PNG in LibreOffice Draw

Exporting vector artwork to a transparent PNG in LibreOffice Draw allows you to save graphics, logos, and icons without an unwanted white background. This guide provides a direct, step-by-step process to configure your export settings in LibreOffice Draw to ensure transparency is properly preserved and only the intended artwork is saved.

Step 1: Select Your Vector Artwork

Open your document in LibreOffice Draw and use the cursor to select the specific vector objects, shapes, or grouped artwork you want to export. If you want to export multiple elements together, select all of them or group them by pressing Ctrl + G (or Cmd + G on macOS).

Step 2: Open the Export Dialog

With your artwork selected, go to the top menu and click File > Export... (do not choose Export As, as standard Export provides direct image formatting options).

Step 3: Choose File Format and Enable Selection

  1. In the file browser dialog that appears, choose a destination and name for your file.
  2. In the File type (or Filter) dropdown menu, select PNG - Portable Network Graphic (.png).
  3. Check the Selection checkbox. This ensures only the selected objects are exported rather than the entire page canvas.
  4. Click Save or Export.

Step 4: Configure Transparency in PNG Options

After clicking Save, the PNG Options dialog window will appear:

  1. Locate the Save transparency option and make sure the checkbox is checked.
  2. (Optional) Adjust the Width, Height, or Resolution (DPI) if you need higher-resolution output for print or web.
  3. Set the Compression level according to your file size preference (standard compression defaults to 6).
  4. Click OK.

Your vector artwork is now exported as a PNG file with a fully transparent background, ready for use in web design, documents, or other graphic projects.
