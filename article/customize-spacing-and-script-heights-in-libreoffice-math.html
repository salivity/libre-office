Customize Spacing and Script Heights in LibreOffice Math

This article provides a direct guide on adjusting operator spacing and modifying the heights and positioning of subscripts and superscripts in LibreOffice Math. By utilizing the built-in Spacing formatting menu and inline markup commands, you can achieve precise visual formatting for mathematical formulas and apply these preferences across all your documents.

Accessing the Global Spacing Settings

To modify default measurements across a formula:

  1. Open your formula in the LibreOffice Math editor.
  2. Click Format in the top menu and select Spacing.
  3. Click the Category button in the dialog window to reveal the dropdown menu of adjustable elements.

Adjusting Subscript and Superscript Heights

To change the positioning and size of subscripts and superscripts (indexes):

  1. In the Spacing dialog, click Category and select Indexes.
  2. Modify the following parameters as needed:
    • Subscript: Adjust the percentage to move subscripts closer to or farther below the baseline.
    • Superscript: Adjust the percentage to control how high superscripts appear above the baseline.
  3. Click OK to apply the changes to the current formula.

Customizing Operator Spacing

To adjust the distance between operators (such as +, -, =, or integral signs) and adjacent variables:

  1. In the Spacing dialog, click Category and choose Operators.
  2. Modify the values:
    • Excess size: Adjusts the minimum distance between the operator and the top/bottom limits.
    • Spacing: Controls the horizontal space added to the left and right of the operator.
  3. Click OK to apply the settings.

Making Changes the Default for Future Formulas

If you want your custom script heights and operator spacing to apply to all new formulas automatically:

  1. Open Format > Spacing.
  2. Adjust all desired categories.
  3. Click the Default button at the bottom of the dialog.
  4. Confirm the prompt to save the configuration as the standard template.

Inline Adjustments Using Code Markup

If you only need to adjust spacing or placement for specific elements without changing global formula properties, use the following code commands directly in the equation editor:

  • Small space: Use a grave accent (`) to add a narrow space (e.g., a + b).
  • Wide space: Use a tilde (~) to insert a standard blank space (e.g., a ~ + ~ b).
  • Remove spacing: Use nospace { ... } to eliminate default padding around specific terms.
  • Custom vertical shifts: Group terms with rsub (subscript) or rsup (superscript) combined with font size commands, such as x rsup { size -2 { 2 } }.
