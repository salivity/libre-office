How to Distribute Objects Evenly in LibreOffice Draw

Distributing objects evenly in LibreOffice Draw allows you to arrange multiple shapes or elements with consistent gaps between them, ensuring a clean and professional layout. This guide explains how to use the built-in Distribution tool to apply equal horizontal and vertical spacing across your selected objects quickly and precisely.

Step 1: Select the Objects

  1. Open your document in LibreOffice Draw.
  2. Select at least three objects that you want to distribute. You can do this by clicking and dragging a selection box over them, or by holding down the Shift key while clicking each object individually.

Step 2: Open the Distribution Dialog

You can access the distribution settings through several methods:

  • Menu Bar: Go to Shape > Distribute Selection... (or Format > Distribute Selection... depending on your LibreOffice version).
  • Context Menu: Right-click on any of the selected objects and choose Distribute Selection....

Step 3: Set Horizontal and Vertical Spacing

In the Distribution dialog window, you will see options for both horizontal and vertical positioning:

  • For Equal Horizontal Spacing: Under the Horizontal section, select the Spacing option. This calculates equal distance between the edges of adjacent objects rather than aligning their centers.
  • For Equal Vertical Spacing: Under the Vertical section, select the Spacing option.

Note: You can apply both horizontal and vertical spacing simultaneously within the same dialog.

Step 4: Apply the Changes

Click OK to apply the settings. LibreOffice Draw keeps the outermost objects fixed in place as anchors and shifts the inner objects so that the empty space between each consecutive object is identical.
