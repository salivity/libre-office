LibreOffice Writer Image Anchor Modes Explained

When inserting images into LibreOffice Writer, understanding anchor modes is essential for controlling how images interact with surrounding text and layout changes. This guide provides a clear overview of how anchoring works, breaking down the specific behaviors of To Paragraph, To Character, As Character, and To Page so you can choose the right setting for any document layout.

What Is an Anchor in LibreOffice Writer?

An anchor is a reference point that attaches an image to a specific part of a document. It determines what the image moves with when you add, delete, or rearrange content. Choosing the correct anchor prevents images from jumping to unexpected locations or overlapping text.

1. To Paragraph

  • How it works: The image is anchored to a specific paragraph.
  • Behavior: When you add or delete text above the paragraph, the paragraph moves up or down, and the image moves along with it. However, the image retains its relative horizontal and vertical position compared to that paragraph or the page margins.
  • Text Wrapping: Fully supported. Text can wrap around the image (Before, After, Parallel, Through, etc.).
  • Best used for: Illustrative images, charts, and figures that belong directly to a specific section or block of text.

2. To Character

  • How it works: The image is tied to a specific character in a line of text.
  • Behavior: Similar to "To Paragraph," the image moves as text shifts. The key difference is that the anchor point is a single character rather than the paragraph container. The image acts as a floating object positioned relative to that character.
  • Text Wrapping: Fully supported. Text flows around the image based on your wrapping settings.
  • Best used for: Callout boxes, side notes, or small visuals closely associated with a specific word or phrase rather than an entire paragraph.

3. As Character

  • How it works: The image is treated literally as a text character inside the line of text.
  • Behavior: The image sits on the baseline of the text line, just like an oversized letter. It moves horizontally and vertically as words are typed. If the image is taller than the font size, the line spacing expands automatically to accommodate it.
  • Text Wrapping: Not applicable. Text cannot wrap around the image because the image is part of the text stream itself.
  • Best used for: Inline icons, mathematical formulas, symbols, and logos placed inside a sentence or heading.

4. To Page

  • How it works: The image is fixed to a specific page number, completely independent of the text.
  • Behavior: If text shifts across pages due to editing, the image stays on the exact page number where it was anchored. If text moves from Page 2 to Page 3, an image anchored "To Page 2" remains on Page 2, even if the text it originally accompanied has moved away.
  • Text Wrapping: Supported on the target page.
  • Best used for: Fixed-layout documents, cover pages, background graphics, watermarks, or newsletter layouts where visual elements must remain in a precise location regardless of text flow.

Quick Comparison Summary

Anchor Mode Moves With Text? Supports Text Wrap? Best For
To Paragraph Yes (moves with paragraph) Yes General figures, charts, diagrams
To Character Yes (moves with specific character) Yes Side notes, word-specific graphics
As Character Yes (flows inline with text) No Icons, inline formulas, symbols
To Page No (remains on fixed page) Yes Cover designs, fixed newsletters

How to Change the Anchor Mode

  1. Right-click the image in LibreOffice Writer.
  2. Hover over the Anchor submenu.
  3. Select your preferred anchor mode (To Page, To Paragraph, To Character, or As Character).
