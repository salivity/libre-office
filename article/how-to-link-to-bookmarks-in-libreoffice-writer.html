How to Link to Bookmarks in LibreOffice Writer

Navigating large documents in LibreOffice Writer is made significantly easier by linking text directly to specific sections. This guide provides a straightforward walkthrough on how to insert bookmarks as target points within a single document and how to create clickable internal hyperlinks that jump instantly to those designated targets.

Step 1: Insert a Bookmark

A bookmark serves as the destination target for your internal link.

  1. Place your text cursor at the exact location, heading, or paragraph where you want the reader to land.
  2. Open the top menu and select Insert > Bookmark....
  3. In the pop-up dialog box, type a clear, recognizable name for your bookmark.
  4. Click Insert to save the bookmark.

Step 2: Create the Hyperlink Jump

Once the bookmark is established, you can create a link from any text in the same document that points to it.

  1. Highlight the text you want to use as the clickable link.
  2. Open the top menu and select Insert > Hyperlink... (or press Ctrl + K on Windows/Linux or Cmd + K on macOS).
  3. In the Hyperlink dialog window, select the Document category from the left panel.
  4. In the "Target in Document" section, click the Target in Document icon (represented by a small crosshair/circle icon next to the Target field).
  5. In the list that appears, click the expand arrow next to Bookmarks.
  6. Select the name of the bookmark you created in Step 1.
  7. Click Apply, then click Close on the target selector.
  8. Click Apply and OK in the main Hyperlink dialog window.

Step 3: Test the Internal Link

By default, LibreOffice Writer requires a modifier key to activate hyperlinks in edit mode.

  • Hold down the Ctrl key (or Cmd on macOS) and click on the linked text.
  • The cursor and view will immediately jump to the position of the assigned bookmark.

(Note: You can also use this same hyperlink process to jump directly to standard document Headings without creating bookmarks first, by selecting the heading from the "Headings" list in the Target dialog.)
