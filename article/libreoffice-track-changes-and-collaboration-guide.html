LibreOffice Track Changes and Collaboration Guide

LibreOffice Writer provides a robust, built-in system for tracking changes, adding comments, and managing collaborative document editing. This article outlines how to enable change tracking, manage visual edits, navigate comments, and merge or compare documents to facilitate seamless collaboration among multiple reviewers, including users working across different office suites.

Enabling and Recording Changes

To start tracking modifications in a document, navigate to Edit > Track Changes > Record or use the keyboard shortcut Ctrl + Shift + C (Cmd + Shift + C on macOS). Once activated:

  • Deletions: Text removed by an editor is displayed with a strikethrough line.
  • Insertions: Newly added text appears in a distinct color assigned automatically to the author.
  • Attribute Changes: Formatting alterations, such as bolding or font resizing, are noted in the margins or tracked visually.

To temporarily hide markup without disabling tracking, toggle Edit > Track Changes > Show.

Customizing Author Details

Because LibreOffice associates track changes and comments with the current user's profile, it is essential to configure user metadata. Go to Tools > Options > LibreOffice > User Data (or LibreOffice > Preferences > User Data on macOS) and enter your name and initials. This ensures every edit and note is accurately attributed.

Adding and Managing Comments

Comments facilitate contextual discussions alongside tracked edits:

  • Insert a Comment: Select the relevant text and choose Insert > Comment or press Ctrl + Alt + C.
  • Reply to Comments: Click the dropdown arrow on an existing comment box and select Reply.
  • Resolve or Delete: Right-click a comment to mark it as resolved or delete it individually, by author, or in bulk.

Reviewing and Finalizing Edits

The Track Changes Toolbar (accessible via View > Toolbars > Track Changes) provides essential controls for document finalization:

  • Navigate: Use the Previous and Next change buttons to step through edits sequentially.
  • Accept or Reject Individual Changes: Click Accept Change or Reject Change to process edits one at a time.
  • Batch Processing: Choose Accept All or Reject All to finalize the entire document at once.
  • Manage Changes Dialog: Access Edit > Track Changes > Manage to view a comprehensive list of all edits, filterable by author, date, or comment.

Comparing and Merging Documents

For asynchronous collaboration where different authors edited separate copies of a file:

  • Compare Document: Open the modified file and go to Edit > Track Changes > Compare Document. Select the original file to view the differences highlighted as tracked changes.
  • Merge Document: To combine edits from multiple reviewers working on copies of the same base file, go to Edit > Track Changes > Merge Document and select the edited files.

Interoperability with Microsoft Word

LibreOffice fully supports the import and export of tracked changes and comments in Microsoft Word formats (.docx and .doc). When saving files intended for Microsoft Word users, ensure the document is saved in the .docx format; all recorded changes, author names, and comments will remain intact and editable in Word.
