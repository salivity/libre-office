LibreOffice Accessibility Tools and Screen Readers

LibreOffice includes a comprehensive suite of accessibility features and assistive technology integrations designed to ensure all users can create, edit, and read documents effectively. This guide covers the software's screen reader compatibility across multiple operating systems, its automated accessibility verification tools, interface customization options, and accessible document export capabilities.

Screen Reader Support Across Platforms

LibreOffice interfaces directly with standard assistive technology protocols across major desktop operating systems:

  • Windows: LibreOffice supports the IAccessible2 standard, allowing screen readers such as NVDA (NonVisual Desktop Access) and JAWS (Job Access With Speech) to read document text, interface menus, dialog boxes, and formatting properties. Legacy Java Access Bridge support is also available when Java integration is enabled.
  • Linux: The suite integrates natively with the AT-SPI (Assistive Technology Service Provider Interface) framework, enabling seamless interaction with the Orca screen reader in desktop environments such as GNOME and KDE.
  • macOS: LibreOffice interfaces with Apple’s NSAccessibility protocol, providing compatibility with the built-in VoiceOver screen reader for navigating documents and controls.

Built-In Accessibility Checker

LibreOffice Writer, Calc, and Impress include an integrated Accessibility Check tool (accessible via Tools > Accessibility Check). This utility audits the active document against universal accessibility standards (such as PDF/UA and WCAG) and flags potential barriers, including:

  • Missing Alternative Text: Identifies images, graphics, and OLE objects that lack descriptive text.
  • Heading Structure: Detects skipped heading levels (e.g., jumping from Heading 1 directly to Heading 3) to ensure a logical document outline.
  • Table Formatting: Checks for defined header rows and flags split or merged cells that disrupt reading order.
  • Hyperlink Text: Warns about generic hyperlink text (such as "click here") that lacks contextual clarity for screen readers.
  • Contrast and Text Formatting: Flags low-contrast text choices and simulated formatting (such as using multiple empty paragraphs instead of standard spacing).

Visual and Interface Customization

LibreOffice provides several visual adjustments to assist users with low vision or visual impairments:

  • High-Contrast Support: Automatically detects system-level high-contrast themes and adjusts document backgrounds, text colors, and UI elements accordingly.
  • Icon and Font Scaling: Users can select high-contrast icon sets (such as Sifr) and scale interface elements, menu fonts, and toolbar sizes via Tools > Options > LibreOffice > View.
  • Custom Color Schemes: Tools > Options > LibreOffice > Application Colors allows users to customize background colors, font colors, field shadings, and gridline appearances to enhance readability.

Comprehensive Keyboard Navigation

The entire LibreOffice suite can be operated without a mouse:

  • Menu and Dialog Navigation: Full support for F6 cycling between document areas, toolbars, sidebars, and status bars.
  • Configurable Shortcuts: Every command and macro can be mapped to custom key combinations under Tools > Customize > Keyboard.
  • Mnemonic Keys: Standard Alt-key shortcuts provide direct access to every menu and sub-menu entry.

Accessible Document Creation and Export

To ensure content remains accessible outside the application, LibreOffice offers advanced export settings:

  • Tagged PDF Export: Creates a structured layout tree within the PDF that screen readers rely on for reading order.
  • PDF/UA Compliance: Supports the universal PDF/UA (Universal Accessibility) standard during export.
  • Alt-Text Editors: Built-in dialogs for assigning titles and alternative descriptions to all visual elements, including drawings, shapes, charts, and mathematical formulas.
