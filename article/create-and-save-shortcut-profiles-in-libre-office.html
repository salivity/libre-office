Create and Save Shortcut Profiles in LibreOffice

Customizing keyboard shortcuts in LibreOffice streamlines your workflow by allowing you to map frequently used commands to your preferred key combinations. This guide explains how to access the keyboard configuration menu, assign custom key bindings either globally or for specific applications like Writer or Calc, export these settings into a .cfg configuration file for backup or transfer, and load saved shortcut profiles whenever needed.

Access the Keyboard Customization Menu

  1. Open any LibreOffice application (such as Writer or Calc).
  2. Click Tools in the top menu bar.
  3. Select Customize... from the dropdown menu.
  4. In the Customize dialog window, click on the Keyboard tab.

Choose the Scope for Your Shortcuts

At the top right of the Keyboard tab, select where you want your custom shortcuts to apply:

  • LibreOffice: Applies the shortcuts across all LibreOffice modules (Writer, Calc, Impress, Draw, etc.).
  • [Module Name] (e.g., Writer): Restricts the custom shortcuts to the currently active application only.

Create Custom Shortcuts

  1. In the Shortcut Keys list at the top, select the key combination you want to assign.
  2. In the Functions section at the bottom:
    • Select a Category (e.g., Edit, Format, Insert).
    • Select the specific Function (command) you want to trigger.
  3. Click the Assign button located on the top right. The chosen function will appear next to the key combination in the list.
  4. Repeat this process for any additional shortcuts you wish to configure.

Save Shortcuts to a File

  1. In the same Keyboard tab, locate the buttons on the right side.
  2. Click the Save... button.
  3. In the file browser dialog, choose a destination folder and enter a name for your configuration profile.
  4. Ensure the file type is set to LibreOffice Keyboard Configuration (*.cfg).
  5. Click Save.

Load a Saved Shortcut Profile

  1. Open Tools > Customize > Keyboard.
  2. Click the Load... button on the right side.
  3. Browse to and select your saved .cfg file.
  4. Click Open.
  5. Click OK at the bottom of the Customize dialog to apply and activate the loaded profile.
