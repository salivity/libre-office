How to Hide and Unhide Sheets in LibreOffice Calc

Managing multiple sheets in LibreOffice Calc can quickly clutter your workspace, but you can easily hide sheets containing background calculations or sensitive data without deleting them. This guide provides quick, step-by-step instructions on how to hide and unhide entire worksheets in LibreOffice Calc using both context menus and the top navigation bar.

How to Hide a Worksheet

You can hide any worksheet in your workbook as long as at least one other worksheet remains visible.

Method 1: Using the Sheet Tab (Right-Click)

  1. Locate the sheet tab at the bottom of the Calc window.
  2. Right-click on the tab of the sheet you want to hide.
  3. Select Hide Sheet from the context menu.

Method 2: Using the Main Menu

  1. Click on the sheet tab you wish to hide to make it active.
  2. Go to the top menu bar and click Sheet.
  3. Select Hide Sheet from the dropdown list.

Hiding Multiple Sheets at Once

  1. Hold down the Ctrl key (or Cmd on macOS) and click each sheet tab you want to hide. To select a continuous range, click the first tab, hold Shift, and click the last tab.
  2. Right-click any of the selected tabs.
  3. Click Hide Sheet.

How to Unhide a Worksheet

When you need to view or edit hidden data, you can restore hidden sheets in just a few clicks.

Method 1: Using the Sheet Tab (Right-Click)

  1. Right-click on any currently visible sheet tab at the bottom of the screen.
  2. Select Show Sheet... from the menu.
  3. In the Show Sheet dialog box, select the name of the hidden sheet you want to restore. To select multiple sheets, hold Ctrl while clicking.
  4. Click OK to make the sheet(s) visible again.

Method 2: Using the Main Menu

  1. Go to the top menu bar and click Sheet.
  2. Select Show Sheet....
  3. Choose the sheet(s) you want to display from the list.
  4. Click OK.
