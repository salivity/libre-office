How to Link Zotero and Mendeley to LibreOffice Writer

Connecting a reference manager like Zotero or Mendeley to LibreOffice Writer allows you to insert in-text citations and automatically generate bibliographies directly within your documents. This guide outlines the straightforward steps required to install the necessary extensions and integrate both reference management tools into LibreOffice Writer seamlessly.

Prerequisites: Enable Java in LibreOffice

Both Zotero and Mendeley require the Java Runtime Environment (JRE) to communicate with LibreOffice Writer.

  1. Open LibreOffice Writer.
  2. Navigate to Tools > Options (on macOS: LibreOffice > Preferences).
  3. Under the LibreOffice section on the left, click Advanced.
  4. Check the box labeled Use a Java runtime environment.
  5. Select an installed JRE from the list and click OK. (If none appears, download and install a 64-bit JRE from the official Java website, then restart LibreOffice).

How to Link Zotero to LibreOffice Writer

Zotero bundles its LibreOffice integration extension within the desktop application.

  1. Download, install, and open the Zotero desktop application.
  2. In Zotero, navigate to Edit > Preferences (on macOS: Zotero > Settings).
  3. Click the Cite tab at the top of the preferences window.
  4. Select the Word Processors tab.
  5. Click Install LibreOffice Plugin (or Reinstall LibreOffice Plugin if previously attempted).
  6. Follow the on-screen prompts and click OK.
  7. Restart LibreOffice Writer. A dedicated Zotero toolbar will now appear in your workspace.

How to Link Mendeley to LibreOffice Writer

The native LibreOffice integration is available via Mendeley Desktop.

  1. Download, install, and open Mendeley Desktop.
  2. Ensure LibreOffice Writer is completely closed.
  3. In Mendeley Desktop, click the Tools menu at the top.
  4. Select Install LibreOffice Plugin.
  5. A confirmation dialog will notify you when the installation is complete.
  6. Open LibreOffice Writer. The Mendeley toolset will be visible in the top menu or as a dedicated toolbar.

Verifying and Using the Toolbars

Once installed, you can use the respective toolbars in LibreOffice Writer to:

  • Add/Edit Citation: Search your library and insert citations into your text.
  • Insert Bibliography: Generate a complete list of references based on your citations.
  • Document Preferences: Change citation styles (e.g., APA, IEEE, Chicago) at any point during writing.
