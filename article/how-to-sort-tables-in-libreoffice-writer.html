How to Sort Tables in LibreOffice Writer

LibreOffice Writer provides a built-in sorting tool that allows you to organize table data alphabetically or numerically in ascending or descending order. This guide walks you through the step-by-step process of sorting single or multiple columns in a table while ensuring header rows remain unaffected.

Step 1: Select the Table Data

  1. Click anywhere inside the table you want to sort.
  2. If your table has a header row that should not be sorted, highlight only the rows containing data. Alternatively, you can select the entire table if it does not contain headers.

Step 2: Open the Sort Dialog

  1. Navigate to the top menu bar.
  2. Click on Table.
  3. Select Sort... from the dropdown menu to open the Sort dialog window.

Step 3: Configure Sort Criteria

In the Sort dialog, you can define up to three levels of sorting criteria (Key 1, Key 2, and Key 3):

  1. Column: Under Key 1, choose the column number you want to use as the primary sorting rule.
  2. Key Type:
    • Select Alphanumeric to sort text alphabetically (A–Z or Z–A).
    • Select Numeric to sort numbers by value (lowest to highest or highest to lowest).
  3. Order:
    • Choose Ascending for A–Z or lowest to highest.
    • Choose Descending for Z–A or highest to lowest.
  4. Secondary Sorting (Optional): If you have duplicate values in the first column and want to break ties, configure Key 2 and Key 3 using the same method.

Step 4: Set the Sort Direction and Language

  1. In the Direction section, ensure Rows is selected (this ensures entire rows are moved together).
  2. Adjust the Language setting if your data requires specific locale-based sorting rules.

Step 5: Apply the Changes

Click OK at the bottom of the dialog. LibreOffice Writer will rearrange the selected rows according to your specified criteria.
