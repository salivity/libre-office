Watermark Options for All Pages in LibreOffice Writer

LibreOffice Writer provides several methods to apply text and image watermarks across every page of a document. Users can choose between the native text watermark tool for quick text overlays, page background settings for full-page images or graphics, and header-anchored objects for precise graphical customization. This guide explains each watermarking option available in LibreOffice Writer and how to configure them for document-wide application.

1. Built-in Text Watermark Feature

The built-in text watermark tool is the fastest way to add a standard text watermark across all pages in a document.

  • How to access: Go to Format > Watermark... in the top menu.
  • Customization options:
    • Text: Enter any custom string (e.g., CONFIDENTIAL, DRAFT, DO NOT COPY).
    • Font: Select any installed system font.
    • Angle: Adjust the rotation angle (standard is 45 degrees for diagonal display, or 0 degrees for horizontal).
    • Transparency: Set the opacity percentage (typically 25% to 50%) to ensure underlying document text remains legible.
    • Color: Choose any custom font color.
  • Scope: Once applied, the watermark automatically repeats across all pages and locks behind the text layer.

2. Page Style Background (Image and Bitmap Watermarks)

To use a custom logo, graphic, or pre-designed background watermark across all pages, configure the Page Style settings.

  • How to access: Go to Format > Page Style... (or right-click the page and select Page Style), then navigate to the Area tab.
  • Customization options:
    • Image / Bitmap: Click the Image or Bitmap button to import a custom file (PNG, JPG, SVG).
    • Style / Placement: Choose how the image sits on the page—Custom position/size, Stretched, or Tiled.
    • Transparency: Switch to the Transparency tab within the same dialog to apply uniform transparency across the entire background graphic.
  • Scope: The image applies to every page that shares the active Page Style (by default, the "Default Page Style" governs the entire document).

3. Header-Anchored Graphic or Fontwork

For advanced control over position, layering, and formatting of graphic watermarks, anchor an object to the page header. Objects anchored within headers automatically repeat on every page associated with that header.

  • How to implement:
    1. Click into the header area (Insert > Header and Footer > Header > Default Page Style).
    2. Insert an image (Insert > Image...) or vector shape/Fontwork (Insert > Fontwork...).
    3. Right-click the object and select Anchor > To Character (or To Paragraph).
    4. Right-click the object and select Wrap > In Background (or Arrange > To Background).
    5. Use the Image or Drawing toolbar to adjust transparency, color mode (e.g., Watermark or Grayscale), and sizing.
  • Customization options:
    • Complete control over sizing, exact coordinates, rotation angles, and borders.
    • Capability to use vector graphics (SVG) for high-resolution printing.
  • Scope: Displays automatically on every page running the configured header style.
