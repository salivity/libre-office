How to Print Notes and Handouts in LibreOffice Impress

LibreOffice Impress allows you to print presentations in dedicated formats tailored for different presentation needs, including speaker notes for your personal reference and multi-slide handouts for your audience. Configuring these formats is straightforward and managed directly within the main print settings menu.

How to Print Presentation Speaker Notes

Speaker notes print each slide on an individual page with its corresponding slide notes positioned directly beneath the slide thumbnail.

  1. Open your presentation in LibreOffice Impress.
  2. Ensure you have added your presentation notes in the Notes pane beneath each slide (or via View > Notes).
  3. Click File in the top menu and select Print (or press Ctrl + P on Windows/Linux, Cmd + P on macOS).
  4. In the Print dialog window, select the LibreOffice Impress tab.
  5. Locate the Document section and click the dropdown menu next to Type.
  6. Select Notes from the list.
  7. Verify the layout in the print preview panel on the left side of the dialog.
  8. Select your printer and click Print.

How to Print Audience Handouts

Handouts allow you to print multiple slides per page to save paper and provide attendees with a physical reference of your presentation.

  1. Click File and select Print (or press Ctrl + P / Cmd + P).
  2. Go to the LibreOffice Impress tab.
  3. In the Document dropdown menu, change the Type to Handouts.
  4. Configure your handout preferences:
    • Slides per page: Choose whether to print 1, 2, 3, 4, 6, or 9 slides per sheet. Selecting 3 slides per page automatically generates lined space next to each slide for audience notes.
    • Order: Choose between Horizontal (left-to-right) or Vertical (top-to-bottom) slide ordering.
  5. Review the page arrangement in the preview panel.
  6. Click Print.

Customizing Handout Layouts

If you need to adjust headers, footers, page numbering, or slide orientations for your handouts before printing:

  1. Click View in the top menu bar.
  2. Select Master Handout.
  3. Move, resize, or edit the header, footer, date, and page number fields as needed.
  4. When finished, return to the regular presentation mode by clicking View > Normal.
