Manage Chapter Numbering in LibreOffice Writer

Managing chapter numbering hierarchies in LibreOffice Writer allows you to automatically number headings, create multi-level outlines (such as 1.1, 1.1.1), and maintain consistent document structure. By utilizing the dedicated Chapter Numbering tool located within the Tools menu, you can map specific paragraph styles to outline levels, define numbering formats, and adjust spacing for seamless document navigation and automated table of contents generation.

Accessing the Chapter Numbering Dialog

To begin setting up your numbering structure:

  1. Open your document in LibreOffice Writer.
  2. Click on Tools in the top menu bar.
  3. Select Chapter Numbering (labeled as Outline Numbering in some older versions).

Configuring Hierarchy Levels and Number Formats

The Numbering tab within the Chapter Numbering dialog controls how each heading level behaves and displays:

  1. Select a Level: On the left pane, choose the hierarchy level you want to configure (Level 1 represents main chapters, Level 2 represents subheadings, and so on). You can select 1–10 to apply changes globally.
  2. Assign Paragraph Styles: In the Paragraph style dropdown, link a style to the selected level. By default, Level 1 uses Heading 1, Level 2 uses Heading 2, and so forth.
  3. Choose Numbering Style: Under the Number dropdown, choose your numbering scheme (such as 1, 2, 3, A, B, C, i, ii, iii, or None).
  4. Set Displayed Sublevels: In the Sublevels field, specify how many previous levels should appear in the current level's number. For example, setting Sublevels to 2 on Level 2 produces a format like 1.1.
  5. Add Separators:
    • Use the Before field to add text or characters before the number (e.g., typing "Chapter " results in "Chapter 1").
    • Use the After field to add punctuation after the number (e.g., a period or colon like "1.1.").

Adjusting Alignment and Indentation

Switch to the Position tab to control the physical spacing between the numbers and the heading text:

  1. Level: Select the outline level to adjust.
  2. Numbering followed by: Determine what separates the number from the heading text. Options include:
    • Tab stop: Places a standard tab space after the number.
    • Space: Inserts a single space character.
    • Nothing: Keeps the text directly adjacent to the number.
  3. Aligned at / Indent at: Adjust these numerical fields to specify the exact indentation from the left margin for both the numbers and the heading text.

Applying the Numbering to Your Document

Once your settings are defined, click OK to save the configuration. To apply the hierarchy:

  1. Highlight your text or place the cursor in the heading paragraph.
  2. Apply the assigned style (e.g., Heading 1, Heading 2) using the Apply Style drop-down menu on the formatting toolbar or the Sidebar (F11).
  3. The numbering hierarchy will update automatically throughout the document based on the rules configured in the Tools menu.
