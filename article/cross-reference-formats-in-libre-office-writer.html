Cross-Reference Formats in LibreOffice Writer

Cross-references in LibreOffice Writer allow you to dynamically link to specific sections, headings, bookmarks, footnotes, and captioned objects within your document. This article provides a comprehensive overview of the available cross-reference formats (the "Refer using" options) in LibreOffice Writer, detailing what each format outputs and how they maintain accuracy as your document changes.

Available Cross-Reference Formats

When inserting a cross-reference via Insert > Cross-reference (or pressing Ctrl + F2 and selecting the Cross-references tab), you can choose how the referenced item is displayed in your text using the Refer using list:

  • Page: Displays the exact page number where the referenced target is located (e.g., "page 12"). If the target moves to a different page due to document edits, this number updates automatically.
  • Chapter: Displays the chapter or section number of the heading containing the target (e.g., "2.1").
  • Reference: Inserts the complete text of the referenced target, such as the full text of a heading or bookmark.
  • Above/Below: Generates the word "above" or "below" depending on the target’s position relative to the cross-reference field. If the layout shifts and the target moves from below the reference to above it, the text updates automatically.
  • As Page Style: Inserts the page number using the specific numbering format defined by the target page’s style (for example, Roman numerals iv instead of Arabic numerals 4).
  • Category and Number: Used primarily for captioned elements such as images, tables, or frames. It inserts the object category along with its sequence number (e.g., "Figure 3" or "Table 1").
  • Caption Text: Inserts only the descriptive text associated with a captioned object, excluding the category label and number.
  • Numbering: Inserts the sequence number of a heading, numbered paragraph, or caption without including any accompanying category labels or text.

How to Apply Cross-Reference Formats

  1. Place your cursor where the cross-reference should appear.
  2. Go to the menu bar and select Insert > Cross-reference....
  3. In the Type list on the left, choose the target type (such as Headings, Bookmarks, Figures, or Tables).
  4. In the Selection list in the middle, select the specific item you want to reference.
  5. In the Refer using list on the right, select your desired format from the options described above.
  6. Click Insert to place the dynamic field into your document.
