Display Reviewer Comments in LibreOffice Writer

LibreOffice Writer offers several markup and view options to display reviewer comments and tracked modifications during document collaboration. Reviewers' notes and tracked edits can be viewed in the margin, within dedicated toolbars, or in an organized management dialog. This guide covers the exact settings and markup options required to make all reviewer comments fully visible and manageable in your document.

1. Toggle Comments in the Document Margin

The most common way to view comments alongside the main text is via the margin view:

  • Navigate to View on the top menu bar and check Comments (or press Ctrl + Alt + C on Windows/Linux or Cmd + Option + C on macOS).
  • When enabled, comments appear as colored sticky-note boxes in the right-hand margin, connected by an anchor line to the corresponding text selection.

2. Enable Track Changes Markup Display

If comments are associated with specific tracked edits (insertions, deletions, or format changes), you must ensure that tracked changes are visible:

  • Go to Edit > Track Changes and select Show (or toggle View > Track Changes to open the toolbar).
  • Alternatively, click the Show Track Changes icon on the Track Changes toolbar at the bottom of the workspace.
  • With this enabled, inline strikethrough, underlines, and author-colored revisions will appear in the body text alongside their respective marginal comments.

3. Use the Manage Changes Dialog

For a comprehensive list of all edits and inline reviewer explanations:

  • Go to Edit > Track Changes > Manage... (or press Ctrl + Shift + E).
  • The Manage Changes window displays a structured list showing the reviewer's name, timestamp, action type (insertion/deletion), and any custom comment entered when the edit was made.
  • Selecting an entry in this list automatically highlights the corresponding change and comment in the main document.

4. Customize Display Preferences in Options

To control how comments and changes are visually rendered:

  • Go to Tools > Options (or LibreOffice > Preferences on macOS).
  • Expand LibreOffice Writer in the left sidebar and select Changes.
  • Here you can customize colors for insertions, deletions, and attributes to make specific reviewer markups and annotations easier to distinguish.
