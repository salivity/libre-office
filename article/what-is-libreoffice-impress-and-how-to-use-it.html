What Is LibreOffice Impress and How to Use It

LibreOffice Impress is a free, open-source presentation tool included in the LibreOffice productivity suite, serving as a popular alternative to Microsoft PowerPoint. This article explains what LibreOffice Impress is, explores its core features, and provides a clear guide on how to use it to create, customize, and deliver professional multimedia presentations.

What Is LibreOffice Impress?

LibreOffice Impress is a dedicated presentation software developed by The Document Foundation. It runs across multiple operating systems, including Windows, macOS, and Linux. The software uses the OpenDocument Presentation (.odp) format as its default standard, but it is fully compatible with Microsoft PowerPoint (.ppt and .pptx) files, allowing users to open, edit, and save files without format lock-in.

Impress provides a comprehensive set of tools for building slideshows, including drawing tools, animation capabilities, slide transition effects, and support for multimedia elements like audio, video, and charts.

Key Features of LibreOffice Impress

  • Versatile Viewing Modes: Offers different workspace views, such as Normal (for editing), Outline (for structuring text), Notes (for speaker notes), Handouts (for printing), and Slide Sorter (for reorganizing slides).
  • Rich Multimedia Support: Enables embedding of 2D and 3D graphics, vector artwork, sound clips, and video files.
  • Animation and Transitions: Includes a broad library of entrance, emphasis, and exit animations for slide objects, alongside smooth slide-to-slide transitions.
  • Presenter Console: Gives presenters an integrated view showing current slides, upcoming slides, speaker notes, and an elapsed timer during a presentation.
  • Flexible Export Options: Allows users to export presentations directly to PDF, HTML, or various image formats without requiring third-party tools.

How to Create a Presentation in LibreOffice Impress

1. Starting a New Presentation

When you open Impress, a "Select a Template" dialog appears. You can choose a pre-designed template to establish a consistent visual theme, or choose a blank presentation to start from scratch. Click Open to enter the main workspace.

2. Choosing Slide Layouts

To configure how content appears on a slide:

  1. Select the slide from the left-hand Slides pane.
  2. In the right-hand Sidebar, open the Properties deck.
  3. Under the Layouts section, select a layout that fits your content (e.g., Title Slide, Title and Content, or Two Columns).

3. Adding Text, Images, and Objects

  • Text: Click on any placeholder text box to type. You can format fonts, colors, and alignments via the top toolbar or the Properties sidebar.
  • Images: Go to Insert > Image, select a file from your computer, and place it on the canvas.
  • Shapes and Charts: Use the Insert menu or the left drawing toolbar to add shapes, flowcharts, tables, and data charts.

4. Applying Slide Transitions and Animations

  • Transitions: In the right sidebar, click the Slide Transition icon. Select an effect (such as Fade or Wipe), adjust the speed, and choose whether the transition applies to the current slide or to all slides.
  • Object Animations: Select the specific text block or image you want to animate, click the Animation icon in the sidebar, and click the + (Add) button to apply an effect.

5. Running the Slideshow

Once your slides are ready:

  • Press F5 to start the slideshow from the beginning.
  • Press Shift + F5 to start the slideshow from the currently selected slide.
  • Use the arrow keys, spacebar, or mouse clicks to advance through slides.

6. Saving and Exporting

To save your work:

  • Go to File > Save As and choose ODF Presentation (.odp) for native editing, or select Microsoft PowerPoint (.pptx) if sharing with PowerPoint users.
  • Go to File > Export As > Export as PDF to generate a portable, non-editable document suitable for handouts or digital distribution.
