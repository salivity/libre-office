Compare Two Documents Side by Side in LibreOffice

Comparing different versions of a text is essential for tracking revisions, proofreading, and editing effectively. This guide explains how to use the built-in comparison feature in LibreOffice Writer to automatically highlight differences between two files, manage revisions, and arrange the documents side by side on your screen for a direct visual review.

Step 1: Use the Compare Document Feature

LibreOffice Writer includes a native comparison engine that compares a revised file against an original file and generates a markup view using tracked changes.

  1. Open LibreOffice Writer.
  2. Open either the original document or the revised version of your document.
  3. Go to the top menu and select Edit.
  4. Hover over Track Changes and click Compare Document...
  5. In the file browser dialog, select the second version of the document you want to compare against the open one and click Open.

Step 2: Review Differences with Track Changes

Once the comparison is loaded, LibreOffice displays the open document with all differences marked visually:

  • Deletions are typically shown with a strikethrough.
  • Insertions and additions appear underlined in a different color.
  • A floating Manage Changes dialog box will automatically appear. This window lists every change along with the author, date, time, and type of modification (insertion or deletion).

Step 3: Arrange Documents Side by Side

Because LibreOffice merges differences into a single interactive document window, you can view the original and revised versions side by side using your operating system's window management tools:

  • Windows: Open the original document in one window and the compared/revised document in another. Drag one window to the left edge of your screen until it snaps into place, then select the other document to fill the right half of the screen (or use the shortcut Windows Key + Left/Right Arrow).
  • macOS: Open both document windows. Hover over the green full-screen button in the top-left corner of one window and select Tile Window to Left of Screen, then choose the second document for the right side.
  • Linux: Drag each LibreOffice window to opposite edges of the screen, or use your desktop environment's tiling shortcuts (such as Super + Left/Right Arrow in GNOME).

Step 4: Accept or Reject Changes

To finalize your document after comparing:

  1. Use the Manage Changes dialog box to navigate through each modification using the Find Next and Find Previous buttons.
  2. Click Accept to keep a change or Reject to revert it.
  3. To resolve all differences at once, click Accept All or Reject All.
  4. Once finished, save the file under a new name via File > Save As... to preserve your original versions.
