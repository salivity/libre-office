How to Reset LibreOffice User Profile

Resetting your LibreOffice user profile is the most effective way to resolve application corruption, unexplained crashes, missing interface elements, and performance glitches. The user profile stores personal settings, extensions, custom dictionaries, and cached data, which can become damaged over time. You can safely restore LibreOffice to its default factory state either by using the built-in Safe Mode feature or by manually renaming the profile directory.

Method 1: Reset Using Safe Mode (Recommended)

If LibreOffice can still launch, Safe Mode provides an automated way to reset the profile without digging through system directories.

  1. Open LibreOffice.
  2. Navigate to Help in the top menu and select Restart in Safe Mode.
  3. In the confirmation dialog, click Restart.
  4. When LibreOffice restarts in Safe Mode, select the Reset to factory settings option.
  5. Choose Reset entire user profile for a complete refresh.
  6. Click Apply Changes and Restart.

Method 2: Manual Profile Reset

If LibreOffice crashes on startup and will not open, you must reset the folder manually.

Step 1: Close LibreOffice completely Ensure LibreOffice and any background quick-starters are fully closed via your operating system's Task Manager or Activity Monitor.

Step 2: Locate the User Profile folder

  • Windows: Press Win + R, type %APPDATA%\LibreOffice\4\ and press Enter.
  • macOS: Open Finder, press Cmd + Shift + G, enter ~/Library/Application Support/LibreOffice/4/ and press Enter.
  • Linux: Open your file manager and navigate to ~/.config/libreoffice/4/ (press Ctrl + H to view hidden folders).

Step 3: Rename the folder

  1. Locate the folder named user.
  2. Rename this folder to user-backup or user-old. (Renaming instead of deleting preserves custom templates, autotext, and macros for later recovery).

Step 4: Restart LibreOffice Launch LibreOffice normally. The software will automatically generate a fresh, uncorrupted user folder with default settings.
