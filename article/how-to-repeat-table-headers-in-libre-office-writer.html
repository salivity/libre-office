How to Repeat Table Headers in LibreOffice Writer

When working with large tables in LibreOffice Writer that span across multiple pages, repeating the header row ensures your data remains easy to read and understand. This guide provides a straightforward, step-by-step walkthrough to automatically repeat one or more table header rows at the top of every printed or digital page.

Repeat Header Rows Using Table Properties

  1. Open Table Properties: Right-click anywhere inside your table and select Table Properties... from the context menu, or go to the top menu bar and select Table > Properties....
  2. Navigate to Text Flow: In the Table Format dialog box, click on the Text Flow tab.
  3. Enable Heading Repetition: Under the Options section, check the box labeled Repeat heading.
  4. Set Number of Rows: In the The first [X] rows box, enter the number of header rows you wish to duplicate across pages (the default is 1).
  5. Apply Changes: Click OK.

Set Up Repeating Headers When Inserting a New Table

  1. Go to the top menu and select Table > Insert Table... (or press Ctrl + F12).
  2. Set your desired number of columns and rows.
  3. Check the Heading box.
  4. Check the Repeat heading rows on new pages box and set the number of rows to repeat.
  5. Click Insert.

Important Considerations

  • Automatic Pagination: Headers will automatically appear on subsequent pages only when the table naturally breaks and flows onto a new page.
  • Editing Headers: You only need to edit the text and formatting in the original header on the first page; LibreOffice will automatically update the repeated headers on all following pages.
