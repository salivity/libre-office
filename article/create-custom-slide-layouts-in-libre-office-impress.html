Create Custom Slide Layouts in LibreOffice Impress

Creating custom slide layouts with dedicated content placeholders in LibreOffice Impress allows you to maintain visual consistency and streamline presentation design. This guide covers how to access the Master View, configure customized placeholders for text and media, apply default formatting, and save your setup as a reusable presentation template.

1. Access the Master Slide View

To build custom layouts, you must work within the Master Slide interface rather than standard slide edit mode:

  1. Open a new or existing presentation in LibreOffice Impress.
  2. Navigate to the top menu and select View > Master Slide.
  3. The workspace will shift to Master View, and the Master View toolbar will appear.

2. Create a New Layout

You can modify an existing master or create a new one from scratch:

  1. In the left-hand Slide Pane, right-click an existing master slide and select New Master to create a clean layout, or select Duplicate Master to base your layout on an existing design.
  2. Right-click the newly created master slide and choose Rename Master to give it a descriptive name (e.g., "Comparison Layout" or "Two-Column Media").

3. Insert and Position Content Placeholders

Impress allows you to designate areas specifically for text, images, tables, or generic content:

  1. Use the Master View toolbar or the top menu to insert placeholders.
  2. Choose Insert > Master Presentation Elements to add standard header, footer, slide number, or date/time fields.
  3. To add specific content boxes, insert standard text or object boxes by drawing them onto the slide.
  4. Go to the Properties sidebar (or right-click the placeholder box) to define the content type, size, position, and layer arrangements.

4. Format Placeholder Properties

Define the default styling rules that will apply to content entered into these placeholders:

  1. Select the placeholder frame you want to format.
  2. Use the Properties panel on the right sidebar to adjust default font family, font size, paragraph spacing, bullet styles, and background fills.
  3. For media placeholders, adjust the frame boundaries and alignment settings to ensure inserted media scales correctly.

5. Return to Normal View and Test

  1. Click Close Master View on the floating Master View toolbar, or go to View > Normal.
  2. Add a new slide by clicking Slide > New Slide.
  3. In the right-hand Properties sidebar, locate the Master Slide section and apply your newly created layout to confirm that placeholders accept text, images, and other media as intended.

6. Save as a Reusable Template

To use this layout for future presentations:

  1. Go to File > Templates > Save As Template....
  2. Enter a name for your template and select a template category (such as My Templates).
  3. Check Set as default template if you want Impress to open this layout configuration automatically with every new file.
  4. Click Save.
