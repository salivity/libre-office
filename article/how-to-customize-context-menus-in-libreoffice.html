How to Customize Context Menus in LibreOffice

Customizing context menus in LibreOffice allows you to tailor the right-click options for specific objects—such as text, tables, images, or spreadsheet cells—to fit your workflow. This guide explains how to access the built-in customization settings, select target context menus, and add, remove, or rearrange commands across LibreOffice applications like Writer, Calc, and Impress.

Step 1: Open the Customize Dialog

  1. Open any LibreOffice application (such as LibreOffice Writer or Calc).
  2. Click on Tools in the top menu bar.
  3. Select Customize... from the drop-down list.

Step 2: Navigate to the Context Menus Tab

  1. In the Customize dialog window that appears, click on the Context Menus tab located near the top.
  2. In the Target drop-down menu, select the specific context menu you want to modify. For example, choose Text for the standard text right-click menu or Image for options that appear when right-clicking pictures.
  3. Choose the scope under the Save In field to decide whether the changes apply globally across the entire LibreOffice application or only to the currently active document.

Step 3: Modify Context Menu Entries

The dialog displays two primary columns: Available Commands on the left (or via an "Add" button depending on the interface version) and Assigned Commands on the right.

  • To Add a Command:
    1. Browse the categories under the Category section to locate the desired function.
    2. Select the command from the Function list.
    3. Click the right arrow button (or Add) to move the command into the context menu.
  • To Remove a Command:
    1. Select the command you want to delete from the Assigned Commands list on the right.
    2. Click the Remove button (or the trash/left arrow icon).
  • To Reorder Commands:
    1. Select an item in the Assigned Commands list.
    2. Use the Up and Down arrow buttons on the right side of the list to move the entry to your preferred position.
  • To Insert Separators:
    1. Select the command where you want a visual divider to appear.
    2. Click the Insert button and select Insert Separator.

Step 4: Apply the Changes

  1. Click the OK button in the lower-right corner of the Customize window to save your settings.
  2. Test your changes by returning to your document and right-clicking on the corresponding object type.

How to Reset Context Menus to Default

If you need to revert any unintended changes:

  1. Return to Tools > Customize... > Context Menus.
  2. Select the modified context menu from the Target list.
  3. Click the Reset button at the bottom of the window to restore the original layout.
