LibreOffice Impress Mouse Pointer and Pen Tools

During a presentation in LibreOffice Impress, presenters have access to dedicated on-screen pointer options to emphasize key information and interact with their slides in real time. These features include the default navigation cursor, an interactive drawing pen for freehand annotations, and laser pointer functionality via the Presenter Console. This guide explains each available mouse pointer option, how to activate them during a slideshow, and how to customize your drawing settings.

Available Pointer Options

  • Default Mouse Pointer: The standard system arrow used to navigate between slides, click hyperlinks, or trigger object animations. Impress can be configured to keep this cursor visible at all times or hide it automatically after a brief period of inactivity.
  • Mouse Pointer as Pen: Transforms the cursor into a digital drawing tool. This allows you to draw freehand lines, circle elements, or write notes directly onto slides during a live presentation.
  • Laser Pointer (Presenter Console): When using dual displays with the Presenter Console enabled, Impress provides a simulated laser pointer mode. This casts a high-visibility dot onto the audience screen, letting you highlight specific text or graphics without leaving permanent marks on the slide.

How to Enable the Pen During a Slideshow

To switch from the standard cursor to the drawing tool while your slideshow is actively running:

  1. Right-click anywhere on the active slide.
  2. Select Mouse Pointer as Pen from the context menu.
  3. Left-click and drag across the screen to draw.

To return to standard navigation mode, right-click the slide again and uncheck Mouse Pointer as Pen.

Customizing Pen Color and Width

You can adjust how the pen marks appear on your slides:

  1. While the pen tool is active, right-click the slide and navigate to Pen Width to choose between thin, medium, or thick line strokes.
  2. Right-click and choose Change Pen Color to select from the standard color palette to ensure your annotations contrast well against the slide background.
  3. To remove annotations, right-click and select Erase Ink on Slide to clear recent markings, or simply advance to the next slide (annotations are temporary and do not permanently alter your presentation file unless saved).

Setting Global Pointer Preferences

To configure how the mouse pointer behaves by default before starting your presentation:

  1. Go to the top menu bar and select Slide Show > Slide Show Settings.
  2. Under the Presentation Options section:
    • Check Mouse pointer visible to ensure the cursor does not disappear during inactivity.
    • Check Mouse pointer as pen if you want the drawing tool activated automatically the moment a slideshow begins.
  3. Click OK to save your preferences.
