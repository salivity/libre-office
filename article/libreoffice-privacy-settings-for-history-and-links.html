LibreOffice Privacy Settings for History and Links

LibreOffice includes built-in privacy tools that allow users to control metadata retention, link interaction behaviors, and document modification tracking. This guide covers how to locate and configure the specific settings in LibreOffice that manage document editing history, user metadata, and hyperlink activity to maintain confidentiality and data privacy.

Removing Document Modification History and Metadata

LibreOffice automatically stores editing time, revision counts, author names, and change histories inside document files. You can manage or disable these tracking features through the following methods:

1. Remove Personal Information on Save

To ensure modification details, author names, and timestamps are stripped automatically upon saving:

  1. Open LibreOffice and navigate to Tools > Options (or LibreOffice > Preferences on macOS).
  2. Expand the LibreOffice section in the left panel and select Security.
  3. Under the Security options and warnings section, click the Options... button.
  4. Check the box labeled Remove personal information on saving.
  5. Click OK, then click Apply.

2. Clear Properties and User Data for the Current Document

To wipe existing revision numbers, total editing time, and author data from an open document:

  1. Go to File > Properties.
  2. On the General tab, uncheck Apply user data.
  3. Click the Reset Properties button to clear the cumulative editing time and revision counters.
  4. Click OK and save the document.

3. Disable Track Changes

If document alterations are actively being logged:

  1. Navigate to Edit > Track Changes.
  2. Ensure Record is unchecked to prevent new edits from being logged as tracked revisions.
  3. Select Manage... to accept or reject any previously recorded modifications before sharing the file.

Managing Link Behavior and URL Security

While LibreOffice does not function as a standalone web browser, it monitors and processes hyperlinks embedded in documents. You can configure privacy and security behaviors regarding links:

1. Hyperlink Execution Controls

To prevent accidental link triggering and background requests:

  1. Go to Tools > Options > LibreOffice > Security.
  2. Click Options... under Security options and warnings.
  3. Ensure Ctrl-click required to open hyperlinks is enabled. This prevents background web requests from firing upon a simple click.

2. Clearing Document and URL History

LibreOffice maintains a history of recently opened files and accessed file paths:

  1. Open File > Recent Documents.
  2. Click Clear List to wipe the local history of accessed files and file locations.

Advanced History Settings via Expert Configuration

For granular control over internal history logging (including search history and pick lists):

  1. Navigate to Tools > Options > LibreOffice > Advanced.
  2. Click the Open Expert Configuration button.
  3. Search for org.openoffice.Office.Common/History to view and modify preferences related to history size, stored URL lists, and recent file count limits.
