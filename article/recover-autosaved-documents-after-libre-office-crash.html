Recover Autosaved Documents After LibreOffice Crash

A sudden crash in LibreOffice can disrupt your workflow, but the software includes built-in recovery tools and backup directories to help you retrieve your unsaved work. This guide outlines the exact steps to recover your files using the automatic Document Recovery tool, retrieve documents manually from the backup folder, and configure your settings to prevent future data loss.

Method 1: Use the Automatic Document Recovery Tool

In most cases, LibreOffice will automatically attempt to recover documents the next time you launch the application.

  1. Reopen LibreOffice: Launch the LibreOffice application (Writer, Calc, Impress, etc.).
  2. Review the Recovery Dialog: A "Document Recovery" window will automatically appear, listing the documents that were open when the crash occurred.
  3. Start the Recovery: Click Start (or Next) to begin the recovery process. The status next to each document will change from "Not recovered yet" to "Successfully recovered."
  4. Finish and Save: Click Finish. Once the document opens, immediately go to File > Save As and save it with a new name or overwrite the existing file to preserve the changes.

Method 2: Recover Files from the LibreOffice Backup Folder

If the recovery prompt does not appear, your work may still be saved in LibreOffice's internal backup directory.

Step 1: Find Your Backup Path

  1. Open LibreOffice.
  2. Navigate to Tools > Options (Windows/Linux) or LibreOffice > Preferences (macOS).
  3. In the left panel, expand LibreOffice and select Paths.
  4. Look for the Backups entry to see the exact folder path where backup files are stored.

Step 2: Access the Backup Folder

Default backup paths by operating system:

  • Windows: C:\Users\<Username>\AppData\Roaming\LibreOffice\4\user\backup
  • macOS: /Users/<Username>/Library/Application Support/LibreOffice/4/user/backup
  • Linux: /home/<Username>/.config/libreoffice/4/user/backup

Note: On Windows, the AppData folder is hidden by default. Enable "Hidden items" in File Explorer to view it.

Step 3: Open the Backup File

  1. Open your system’s file manager and navigate to the backup path.
  2. Locate the file corresponding to your lost document (it may have a .bak extension).
  3. Right-click the file, select Open with, and choose LibreOffice.
  4. Save the file in your preferred working folder.

Method 3: Search the System Temporary Folder

If the backup folder is empty, check your operating system's temporary directory for cached versions of the file.

  • Windows: Press Win + R, type %temp%, and press Enter. Sort files by Date modified and look for recently modified files with extensions like .tmp or names related to your document.
  • Linux / macOS: Open a file manager or terminal and navigate to /tmp.

If you find a relevant file, open it directly with LibreOffice to verify its contents.

How to Improve Autosave Settings for the Future

To minimize data loss in the event of future crashes, adjust LibreOffice's autosave frequency:

  1. Go to Tools > Options (or LibreOffice > Preferences).
  2. Expand Load/Save and select General.
  3. Check the box for Save AutoRecovery information every and lower the interval (e.g., to 2 to 5 minutes).
  4. Check the box for Always create backup copy to ensure a duplicate is stored in the backup directory every time you save.
  5. Click Apply and then OK.
