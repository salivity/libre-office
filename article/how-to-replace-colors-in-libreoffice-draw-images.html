How to Replace Colors in LibreOffice Draw Images

LibreOffice Draw features a built-in Color Replacer tool designed to swap specific colors within embedded bitmap and raster images. This feature allows users to select up to four source colors simultaneously using an eyedropper tool and replace them with designated palette colors, utilizing adjustable tolerance levels to accommodate gradients, anti-aliasing, and image compression artifacts.

Accessing the Color Replacer

  1. Open LibreOffice Draw and select the image you want to modify.
  2. Navigate to the top menu bar and click Tools.
  3. Select Color Replacer from the dropdown menu to open the floating tool dialog.

Using the Color Replacer Tool

The Color Replacer dialog provides controls to sample, adjust, and apply your color replacements:

  1. Pick the Source Color: Click the Pipette (Eyedropper) icon in the top-left corner of the Color Replacer window. Move your cursor over the image and click the exact color you want to replace. The selected color will appear in the first row of the source color list.
  2. Select the Replacement Color: In the dropdown menu under Replace with, choose the new color you want to apply in place of the original.
  3. Adjust Tolerance: Set the Tolerance percentage. A lower percentage (e.g., 5%–10%) restricts the replacement strictly to the chosen shade, while a higher percentage includes similar adjacent tones. This is particularly useful for JPEG images that feature slight color variations due to compression.
  4. Replace Multiple Colors (Optional): Check the boxes for rows 2, 3, or 4 and repeat the selection process if you need to swap additional colors in the same operation.
  5. Apply Changes: Click the Replace button at the top right of the dialog to execute the color swap across the selected image.

Key Considerations

  • Supported Formats: The Color Replacer works on bitmap images (such as PNG, JPEG, BMP, and GIF). It does not apply to native vector shapes created directly within Draw, which can be modified directly via the standard fill properties.
  • Non-Destructive Workflow: If the replacement yields unexpected results due to high tolerance, use Ctrl + Z (or Cmd + Z on macOS) immediately to revert the action and adjust the tolerance settings before trying again.
