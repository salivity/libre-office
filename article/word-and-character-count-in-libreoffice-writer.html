Word and Character Count in LibreOffice Writer

LibreOffice Writer includes several built-in tools to monitor document length and text statistics. These features range from real-time counters displayed on the interface to detailed statistical breakdowns and dynamic document fields. Users can easily track total words, characters with or without spaces, pages, and specific selections across their documents.

The Status Bar (Real-Time Counter)

The most direct tool for checking word and character counts is the Status Bar, located at the bottom of the LibreOffice Writer window.

  • Default Display: By default, the Status Bar displays the live word and character count for the entire document (e.g., "1,250 words, 7,800 characters").
  • Selection Mode: When a portion of text is highlighted, the Status Bar automatically updates to show the statistics for the selected text alongside the total document count (e.g., "120 words, 750 characters selected").
  • Customization: Right-clicking the word count area in the Status Bar allows users to toggle between showing words only, characters only, or both.

The Dedicated Word Count Dialog

For a quick side-by-side comparison between the entire document and selected text, LibreOffice Writer provides a dedicated Word Count dialog box.

  1. Navigate to the top menu and select Tools.
  2. Click Word Count.

This window provides an instant breakdown of:

  • Words: Total count for the selection and whole document.
  • Characters (including spaces): Useful for standard publishing requirements.
  • Characters (excluding spaces): Useful for specific academic or character-limited submissions.

Clicking the word count section directly on the Status Bar also acts as a shortcut to open this dialog.

Document Properties Statistics

For comprehensive data that extends beyond words and characters, the Document Properties window provides full structural statistics.

  1. Go to File in the top menu.
  2. Select Properties.
  3. Click on the Statistics tab.

This panel displays:

  • Number of Pages
  • Number of Tables
  • Number of Images
  • Number of OLE Objects
  • Number of Paragraphs
  • Number of Words
  • Number of Characters (with spaces)
  • Number of Characters (without spaces)
  • Number of Lines

Click the Update button within this panel to refresh the data if changes were recently made.

Dynamic Statistic Fields

LibreOffice Writer allows users to insert live-updating word and character counts directly into the document text, headers, or footers.

  1. Place the cursor where the count should appear.
  2. Go to Insert > Field > More Fields... (or press Ctrl + F2).
  3. In the DocInformation tab, select Statistics under the Type column.
  4. Choose Words or Characters under the Select column.
  5. Click Insert.

The inserted field will automatically update as the document is edited and saved.
