Create Custom Envelopes and Labels in LibreOffice

LibreOffice Writer provides dedicated built-in tools for generating custom envelopes and mailing labels, allowing you to design individual mail pieces or automate bulk mailings using connected databases. This guide explains how to configure custom dimensions, format text layouts, synchronize label sheets, and print both envelopes and labels accurately.

Designing Custom Envelopes

LibreOffice Writer includes an envelope wizard that lets you specify recipient details, sender information, page orientation, and custom dimensions.

1. Open the Envelope Dialog

  1. Open a new or existing document in LibreOffice Writer.
  2. Go to the top menu and select Insert > Envelope.

2. Configure Address and Layout Details

The dialog contains three primary tabs:

  • Envelope Tab: Enter the text for both the Addressee and Sender. If you are using a database for mail merge, select your data source, table, and fields from the drop-down menus to insert dynamic merge fields.
  • Format Tab: Select standard envelope sizes (such as #10, DL, or C5) from the Format dropdown. To set custom dimensions, select [User] and manually define the width and height. You can also adjust the exact positioning and character styles for the sender and addressee blocks.
  • Printer Tab: Configure how your printer feeds envelopes (horizontal, vertical, face up, or face down) and select the appropriate paper tray.

3. Insert and Print

  • Click New Document to create a standalone envelope file, or click Insert to attach the envelope as the first page of your active document.
  • Review the layout in the workspace. Make any final font, color, or alignment adjustments directly on the page.
  • Select File > Print to send the envelope to your printer.

Designing Mailing Labels

The Labels tool allows you to create sheets of identical labels or populate individual labels with customer data from a spreadsheet or database.

1. Open the Labels Dialog

  1. Navigate to File > New > Labels.

2. Set Up the Label Sheet

  • Labels Tab:
    • In the Label Text box, type your custom text (e.g., return address) or insert database fields for a mailing list.
    • Under the Format section, choose Labels. Select the manufacturer Brand (such as Avery) and the specific Type number corresponding to your label paper.
  • Format Tab (for Custom Sizes):
    • If your label paper is not listed under predefined brands, switch to the Format tab.
    • Define the Horizontal pitch, Vertical pitch, Width, Height, Left margin, Top margin, Columns, and Rows according to the measurements of your physical label sheet.
  • Options Tab:
    • Select Entire page to fill the full sheet.
    • Check the Synchronize contents box. This adds a floating "Synchronize" button to your document, allowing you to edit the top-left label and automatically replicate the design across all other labels.

3. Generate and Finalize

  1. Click New Document to generate the label grid.
  2. If Synchronize contents was enabled, format the text, fonts, or spacing in the first label (top-left corner), then click the Synchronize Labels floating button to update the rest of the sheet.
  3. Go to File > Print. If using database fields, confirm the prompt to print a form letter to merge the records.
