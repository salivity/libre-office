Enable Dark Mode and Experimental Features in LibreOffice

Modern versions of LibreOffice include native support for dark themes and early access to experimental tools. This guide provides a straightforward, step-by-step walkthrough to activate dark mode for reduced eye strain and unlock experimental features to test upcoming functionalities in your LibreOffice suite.

How to Enable Dark Mode in LibreOffice

LibreOffice allows you to switch the user interface and document canvas to a dark color scheme through the application preferences.

  1. Open LibreOffice (Writer, Calc, or the main application hub).
  2. Open the preferences menu:
    • Windows / Linux: Navigate to Tools > Options.
    • macOS: Navigate to LibreOffice > Preferences.
  3. In the left sidebar, expand the LibreOffice section and click on View.
  4. Locate the Mode dropdown menu under the Appearance heading and select Dark (or System if your operating system is already in dark mode).
  5. (Optional) Under Icon Theme, select an icon set optimized for dark backgrounds, such as Colibre (Dark) or Breeze (Dark).
  6. To make the document canvas dark, navigate to LibreOffice > Application Colors in the left sidebar.
  7. Change the Color Scheme dropdown at the top to LibreOffice Dark.
  8. Click Apply, then click OK.

How to Enable Experimental Features in LibreOffice

Experimental features allow advanced users to test unstable features and new interface enhancements before they are enabled by default.

  1. Open the options window via Tools > Options (Windows/Linux) or LibreOffice > Preferences (macOS).
  2. In the left sidebar, expand the LibreOffice section and select Advanced.
  3. Under the Optional Features section, check the box labeled Enable experimental features (may cause instability).
  4. Click Apply, then click OK.
  5. A prompt will appear asking to restart LibreOffice. Click Restart Now to finalize the changes.
