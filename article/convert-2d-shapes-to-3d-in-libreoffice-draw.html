Convert 2D Shapes to 3D in LibreOffice Draw

This guide explains how to transform standard 2D vector shapes into 3D extrusion objects in LibreOffice Draw. By converting flat paths, basic shapes, and polygons into three-dimensional objects, you can add depth, adjust perspective, configure lighting, and apply custom surface materials directly within the software.

Step 1: Create or Select Your 2D Vector Shape

  1. Open your document in LibreOffice Draw.
  2. Select an existing 2D vector object or draw a new one using the Drawing toolbar (such as a rectangle, circle, polygon, or custom Bézier curve).
  3. Ensure the shape is closed if you want a solid 3D body rather than a hollow ribbon.

Step 2: Convert the Shape to 3D

  1. Click on the 2D object to select it.
  2. Right-click the object to open the context menu.
  3. Hover over Convert and select To 3D.
  4. The shape will instantly convert into a 3D extrusion object with default depth and lighting applied.

(Alternative Method: You can also navigate to the top menu and choose Shape > Convert > To 3D.)

Step 3: Customize 3D Extrusion Settings

Once the object is in 3D, you can modify its appearance using the dedicated 3D-Effects panel:

  1. Right-click the newly converted 3D object and select 3D-Effects (or go to Tools > 3D-Effects).
  2. Use the panel tabs to customize the object:
    • Geometry: Adjust the extrusion depth, rounded edges, segments, and perspective angles.
    • Representation: Change the shading mode (Flat, Gouraud, or Phong) to alter surface smoothness.
    • Illumination: Configure up to eight light sources, customize light colors, and modify ambient lighting.
    • Textures / Material: Set the surface material finish (such as Matte, Plastic, Metal, or Gold) and control specular highlights.
  3. Click the Assign icon (checkmark in the top-right corner of the 3D-Effects window) to apply your changes to the selected object.

Step 4: Rotate and Position the 3D Object

  1. Click the 3D object once to show the standard sizing handles.
  2. Click it a second time (or click the Rotate button on the Standard toolbar) to activate the red rotation handles.
  3. Drag the handles to rotate the 3D extrusion along the X, Y, or Z axes to achieve the desired viewing angle.
