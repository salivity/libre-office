How to Embed Fonts in LibreOffice Impress

Embedding fonts in LibreOffice Impress ensures that your slides retain their intended typography, formatting, and design across different computers, even if the host machine does not have your custom fonts installed. This step-by-step guide explains how to enable font embedding directly within your presentation file and highlights key considerations regarding file size and font licensing.

Step-by-Step Guide to Embedding Fonts

  1. Open Your Presentation: Launch LibreOffice Impress and open the presentation file you want to make portable.
  2. Access Document Properties: Click on the File menu in the top menu bar and select Properties.
  3. Navigate to the Font Tab: In the Properties dialog window that appears, switch to the Font tab.
  4. Enable Font Embedding: Check the box labeled Embed fonts in the document.
  5. Optimize File Size (Optional): Check the sub-option Only embed fonts that are used in the document. This prevents LibreOffice from embedding unused font styles or glyphs, keeping your presentation file size smaller.
  6. Save the Presentation: Click OK to apply the settings, then save your presentation by clicking File > Save (or pressing Ctrl + S on Windows/Linux, Cmd + S on macOS).

Important Considerations

  • File Format Compatibility: Font embedding works natively with OpenDocument Presentation (.odp) files. While LibreOffice can also embed fonts when saving as PowerPoint formats (.pptx), saving as .odp provides the most reliable cross-platform compatibility across LibreOffice installations.
  • Font Licensing: Only fonts with licenses that permit embedding can be included in the document. If a font has digital rights restrictions preventing embedding, LibreOffice will not include it, and the destination system may fall back to default system fonts.
  • Increased File Size: Embedding TrueType (.ttf) or OpenType (.otf) fonts will increase the overall file size of your presentation. Always use the option to embed only used characters if you plan to share the presentation via email.
