How LibreOffice Manages User Privacy and Telemetry

This article provides an overview of how LibreOffice handles user privacy and telemetry data collection. Unlike many proprietary office suites, LibreOffice operates on a strict privacy-first model built on open-source principles. It avoids background tracking, keeps data collection entirely opt-in, and gives users total control over their personal information and document metadata.

Default Telemetry and Usage Tracking

LibreOffice does not collect telemetry or usage data by default. The software does not track keystrokes, feature usage, user habits, or document contents. When you install and use the suite, it operates locally on your machine without transmitting background diagnostic reports to The Document Foundation or any third parties.

Open-Source Transparency

Because LibreOffice is free and open-source software (FOSS), its entire codebase is publicly accessible and auditable. Independent developers, organizations, and security researchers regularly inspect the source code. This transparency guarantees that there are no hidden trackers, analytics scripts, or undisclosed data collection routines embedded within the application.

Crash Reporting and Diagnostics

When an unexpected application crash occurs, LibreOffice may offer an optional crash report dialog.

  • Strictly Opt-In: Crash reports are never sent automatically. The user must explicitly choose to send the report.
  • Content Transparency: The diagnostic report primarily includes technical stack traces, memory dumps, and system specifications necessary to debug the crash. It is designed to exclude document contents and sensitive personal data.

Online Features and Update Checks

LibreOffice includes minimal network-enabled features, all of which prioritize user consent:

  • Automatic Update Checks: The software can periodically check for newer versions. This process only sends basic technical information (such as the current version and OS type) required to retrieve the correct update notification. This feature can be easily disabled in the application settings.
  • Third-Party Extensions and Templates: If you download extensions, templates, or connect to remote document repositories (like Google Drive or Nextcloud), data transfer is restricted solely to the requested integration and is governed by that third-party provider's privacy policy.

Document Metadata Control

LibreOffice provides built-in tools to help users manage and eliminate personal metadata from their files. Users can view, modify, or strip identifying information—such as author names, creation dates, total editing time, and version history—directly from the document properties menu before sharing files with others.
