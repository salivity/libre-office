Install Fonts in LibreOffice on Any OS

Installing OpenType (OTF) and TrueType (TTF) fonts for use in LibreOffice requires adding the font files directly to your operating system. Because LibreOffice retrieves its typography list from your system's font registry, installing a font on Windows, macOS, or Linux makes it instantly accessible within your LibreOffice applications once the software is launched or restarted.

Installing Fonts on Windows

  1. Download the font package and extract the archive if it is in a .zip file.
  2. Locate the .otf or .ttf font file.
  3. Right-click the file and select Install for your personal user account, or Install for all users if you have administrative privileges.
  4. Alternatively, drag and drop the font files directly into the C:\Windows\Fonts directory.

Installing Fonts on macOS

  1. Download and unpack your font file.
  2. Double-click the .otf or .ttf file to open the macOS Font Book preview.
  3. Click the Install Font button in the preview window.
  4. The font will be registered automatically in the Font Book application and made available to all compatible software.

Installing Fonts on Linux

Per-User Installation:

  1. Open your file manager and navigate to your Home directory.
  2. Enable hidden files and check for a .fonts folder (or navigate to ~/.local/share/fonts/). If neither exists, create a folder named fonts inside ~/.local/share/.
  3. Copy your .otf or .ttf files into this directory.
  4. Open the Terminal and refresh the font cache by running: 
    fc-cache -f -v

System-Wide Installation:

  1. Move the font files to /usr/local/share/fonts/ using root permissions: 
    sudo cp /path/to/font.ttf /usr/local/share/fonts/
  2. Update the system font cache: 
    sudo fc-cache -f -v

Accessing the New Fonts in LibreOffice

  1. If LibreOffice Writer, Calc, or Impress is currently running, save your work and close the application completely to ensure the font registry refreshes.
  2. Open LibreOffice.
  3. Highlight the text you wish to format or create a new document.
  4. Open the Font Name dropdown list on the Formatting toolbar, scroll to the name of your installed font, or type the font name directly into the box and press Enter.
