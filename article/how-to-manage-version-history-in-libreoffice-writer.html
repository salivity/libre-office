How to Manage Version History in LibreOffice Writer

LibreOffice Writer includes a built-in feature that allows you to store, manage, and review multiple versions of a document directly inside a single OpenDocument Text (.odt) file. This system eliminates the need to clutter your storage with duplicate files to track revisions, allowing you to capture historical snapshots, compare differences, and restore earlier drafts with ease.

Accessing the Version Control Tool

To manage internal versions, you must save the document in the native OpenDocument format (.odt). Proprietary formats like .docx do not support this built-in internal versioning feature.

  1. Open your document in LibreOffice Writer.
  2. Go to the top menu and select File.
  3. Click on Versions... to open the version management dialog.

Saving a New Version

  1. In the File > Versions window, click the New Version button.
  2. An Insert Version Comment box will appear. Enter a descriptive comment summarizing the changes made (e.g., "First draft completed" or "Revised conclusion").
  3. Click OK.

The new version will now appear in the list with a timestamp, the author name, and your comment.

Viewing and Opening an Earlier Version

Stored versions are opened in read-only mode to prevent accidental overwriting of history:

  1. Open File > Versions....
  2. Select the version you want to view from the list.
  3. Click the Open button.
  4. The selected version opens in a separate, read-only window. If you want to use this version as a new base, choose File > Save As... to create a separate working file.

Comparing Versions

To see exact text changes between an earlier saved version and your current active document:

  1. Open File > Versions....
  2. Highlight the version you wish to check.
  3. Click the Compare button.
  4. Writer will open a comparison view highlighting additions, deletions, and formatting alterations, along with an Accept/Reject Changes toolbar.

Deleting a Version

If a snapshot is no longer needed or you want to reduce the document's file size:

  1. Open File > Versions....
  2. Select the version you want to remove.
  3. Click Delete.
  4. Confirm the deletion when prompted.
