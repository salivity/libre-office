How to Export LibreOffice Documents to PDF

Exporting documents directly to PDF format in LibreOffice is a straightforward process that does not require any third-party plugins or external software. Whether you are using Writer, Calc, or Impress, LibreOffice provides a quick one-click export button for standard documents, as well as an advanced export menu that allows you to customize image compression, page ranges, security settings, and PDF/A compliance.

Method 1: Export Directly as PDF (One-Click)

If you need a standard PDF with default settings, use the quick export feature:

  1. Open your document in LibreOffice.
  2. Click the Export Directly as PDF icon located on the top standard toolbar (represented by a document icon with the PDF logo). Alternatively, navigate to File > Export Directly as PDF.
  3. In the file dialog box, select your desired folder location and enter a file name.
  4. Click Save to generate the PDF instantly.

Method 2: Custom PDF Export (Advanced Settings)

To configure specific settings such as password protection, image quality, or page ranges before exporting:

  1. Open your document in LibreOffice.
  2. Go to the top menu and select File > Export As > Export as PDF....
  3. The PDF Options dialog window will appear with several tabs:
    • General: Set the page range, select image compression levels, and enable PDF/A formats for long-term archiving.
    • Initial View: Define how the PDF opens in a viewer (e.g., page layout, magnification, outline visibility).
    • User Interface: Customize viewer interface elements, such as hiding toolbars or menubars.
    • Links: Control how bookmarks and hyperlinks inside the document behave.
    • Security: Set a password to restrict opening the file, printing, or copying content.
    • Digital Signatures: Attach a digital certificate to sign the PDF securely.
  4. After adjusting your preferred options, click the Export button at the bottom right.
  5. Choose your destination directory, name the file, and click Save.
