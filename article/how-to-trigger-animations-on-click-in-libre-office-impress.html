How to Trigger Animations on Click in LibreOffice Impress

This guide explains how to set up interactive trigger animations in LibreOffice Impress, allowing you to play specific entrance, exit, or emphasis effects only when distinct objects on your slide are clicked during a presentation.

Step 1: Create the Objects

  1. Open your presentation in LibreOffice Impress and navigate to the slide you want to edit.
  2. Insert both the target object (the shape, image, or text you want to animate) and the trigger object (the button, icon, or shape that will be clicked).
  3. If necessary, name your objects in the Navigator panel (F5 on Windows/Linux or via the Sidebar) so they are easy to identify later.

Step 2: Add an Animation to the Target Object

  1. Select the target object that you want to animate.
  2. Open the Animation panel in the Sidebar on the right side of the screen (the star icon).
  3. Click the Add (+) button to add an animation effect (e.g., Appear, Fade, Fly In).

Step 3: Set the Trigger

  1. In the Animation panel list, locate and select the animation effect you just created.
  2. Click the Options button (the icon next to the remove button) or right-click the effect in the list and select Effect Options.
  3. In the dialog window that appears, navigate to the Timing tab.
  4. Click the Triggers button at the bottom of the tab to expand the trigger settings.
  5. Select the Start effect on click of radio button.
  6. From the drop-down menu, choose the trigger object that should activate this animation.
  7. Click OK to apply the changes.

Step 4: Configure Additional Interactive Objects

To assign separate animations to other interactive objects on the same slide:

  1. Select a new target object and add its animation using the Add (+) button.
  2. Open its Effect Options and go to the Timing tab.
  3. Under Triggers, choose Start effect on click of and select the corresponding separate trigger object.

Step 5: Test the Presentation

  1. Start the slideshow by pressing F5 (or Shift + F5 for the current slide).
  2. Hover the mouse over the trigger objects; the cursor will change to a hand icon.
  3. Click each interactive object independently to trigger its assigned animation.
