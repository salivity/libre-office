How to Create Kiosk Presentations in LibreOffice Impress

This guide outlines how to build an interactive kiosk presentation using LibreOffice Impress. By disabling default mouse-click slide transitions, configuring automated loop settings, and creating custom interactive navigation buttons, you can transform a standard slide deck into a secure, self-navigating informational kiosk suitable for trade shows, public lobbies, or educational exhibits.

1. Disable Automatic Mouse-Click Progression

To prevent users from skipping ahead by clicking anywhere on the screen, you must restrict navigation to designated on-screen buttons:

  1. Open your presentation in LibreOffice Impress.
  2. Open the Slide Sorter view (View > Slide Sorter) and press Ctrl + A (or Cmd + A on macOS) to select all slides.
  3. Open the Slide Transition panel in the right sidebar.
  4. Locate the Advance slide section.
  5. Uncheck On mouse click.
  6. Ensure Automatically after is also unchecked for standard interactive slides.

2. Configure Kiosk Display Settings

Configure the presentation to run continuously in full-screen mode:

  1. Navigate to Slide Show > Slide Show Settings from the top menu.
  2. Under the Presentation Mode section, select Auto.
  3. Set the pause duration to 00:00:00 to make the presentation loop immediately to the beginning without displaying a pause screen.
  4. Under the Options section, check Mouse pointer visible so users can see their cursor.
  5. Click OK to apply the settings.

3. Create Navigation Buttons and Links

Interactive kiosks rely on UI elements for navigation:

  1. Insert a shape, icon, or text box onto your slide (Insert > Shape or Insert > Text Box).
  2. Right-click the newly created shape or text element and select Interaction.
  3. In the Action at mouse click dropdown, select Go to page or object.
  4. Choose the target slide you want the button to open (e.g., a specific topic slide, main menu, or return button).
  5. Click OK.
  6. Repeat this process to create "Home", "Back", and "Menu" options across your slides.

4. Use Master Slides for Consistent Navigation

To place permanent navigation controls (such as a "Home" or "Start Over" button) on every slide:

  1. Go to View > Master Slide.
  2. Add your persistent buttons and assign their interactions as described in Step 3.
  3. Click Close Master View in the Master toolbar to apply the layout across all slides that use that master template.

5. Test and Deploy the Kiosk

  1. Press F5 to start the slide show.
  2. Verify that clicking blank areas does not advance the slide.
  3. Test every interactive button to confirm it jumps to the correct slide.
  4. To exit the presentation, press the Esc key. Save your file in .odp format or as a .ppsx / .otp template for quick deployment.
