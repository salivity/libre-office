How to Export Animated GIFs from LibreOffice Impress

LibreOffice Impress allows users to transform slide presentations into looping animated GIF images directly without needing third-party conversion software. This guide covers the exact export process, configuration dialogs, and essential settings required to control animation speed, looping, and visual quality when exporting your presentation as an animated GIF.

Accessing the GIF Export Menu

To begin the export process in LibreOffice Impress:

  1. Open your presentation in LibreOffice Impress.
  2. Ensure each slide represents a single frame of your intended animation.
  3. Click on File in the top menu bar and select Export... (do not select Export As).
  4. In the file browser window, name your file and set the Filter or Save as type dropdown to GIF - Graphics Interchange Format (.gif).
  5. Click Save (or Export) to open the GIF Options dialog.

Essential Animated GIF Export Settings

When the GIF Export Options window appears, configure the following settings to generate an animated file:

1. Animation Mode

  • Animated: You must check the Animated checkbox. Leaving this unchecked will export only the currently selected slide as a single static image.

2. Timing and Playback

  • Frame Delay (Duration): Specifies how long each slide stays on screen before transitioning to the next. This is typically configured in seconds or milliseconds. Set a shorter delay for smooth, fast motion or a longer delay (e.g., 2 to 3 seconds) for reading text.
  • Looping (Repeats): Controls playback repetition. You can choose to loop the animation continuously (infinite loop) or specify a fixed number of repetitions before the GIF stops.

3. Image Dimensions and Resolution

  • Width and Height: Adjust the pixel dimensions to control the final output size. Reducing dimensions significantly lowers the resulting file size.
  • Resolution (DPI): Sets pixel density. Standard web graphics typically use 72 to 96 DPI.

4. Color and Quality Optimization

  • Color Resolution / Number of Colors: GIF is limited to a maximum of 256 colors (8-bit). You can lower the color palette count (e.g., 128, 64, or 32) to reduce file size if your presentation contains simple vector shapes and flat colors.
  • Dithering: Enable dithering if your presentation contains gradients or photographs to prevent harsh color banding across frames.
  • Interlaced: Generates a progressive load effect for web use; typically left unchecked for short, standard animated GIFs.

5. Transparency

  • Save transparency: Check this option if your slides have a transparent background and you want the final GIF to preserve that transparency on web pages or other media.

Once all settings are configured according to your output requirements, click OK to render and export the animated GIF.
