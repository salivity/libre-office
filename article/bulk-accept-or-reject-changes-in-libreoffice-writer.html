Bulk Accept or Reject Changes in LibreOffice Writer

Managing collaborative revisions in LibreOffice Writer does not require reviewing every edit individually. LibreOffice includes built-in tools to accept or reject tracked changes in bulk, which can save significant time on large documents. Users can execute bulk actions using the Track Changes toolbar, the main application menu, or the comprehensive Manage Changes dialog window for filtered bulk operations.

1. The Track Changes Toolbar

The fastest way to handle changes in bulk is via the dedicated toolbar:

  1. Open the toolbar by navigating to View > Toolbars > Track Changes.
  2. To accept all revisions at once, click the Accept All Tracked Changes icon (represented by a document with a double checkmark).
  3. To discard all revisions at once, click the Reject All Tracked Changes icon (represented by a document with a double red cross).

2. The Main Edit Menu

If the toolbar is hidden, the same bulk commands are accessible from the primary menu bar:

  1. Click Edit in the top menu.
  2. Hover over Track Changes.
  3. Select Accept All to apply every recorded change to the document.
  4. Select Reject All to remove all recorded changes and revert the text to its original state.

3. The Manage Changes Dialog

For documents with numerous edits from multiple reviewers, the Manage Changes dialog provides granular control over bulk actions:

  1. Open the dialog by navigating to Edit > Track Changes > Manage... or pressing Ctrl + Shift + C (Cmd + Shift + C on macOS).
  2. The List tab displays all edits, detailing the action, author, date, and text affected.
  3. Use the Accept All or Reject All buttons at the bottom of the window to process the entire document.
  4. Alternatively, use the Filter tab to narrow down changes by author, date, action, or comment. Once filtered, returning to the list allows you to select multiple specific entries using Shift + Click or Ctrl + Click and process only that highlighted subset with Accept or Reject.
