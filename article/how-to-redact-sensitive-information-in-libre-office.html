How to Redact Sensitive Information in LibreOffice

LibreOffice includes a built-in redaction feature designed to permanently obscure sensitive, confidential, or personally identifiable information (PII) from documents. This guide covers how the Redaction tool works, the available masking options, and how to export completely sanitized files using LibreOffice to prevent data leaks.

Accessing the Redaction Tool

The Redaction tool is available in LibreOffice Writer, Calc, and Impress. To start the process:

  1. Open your document.
  2. Navigate to the top menu and select Tools > Redact.
  3. LibreOffice automatically creates a copy of the document and opens it inside LibreOffice Draw, activating the dedicated Redaction Toolbar.

Built-In Redaction Tools

The Redaction toolbar in LibreOffice Draw provides two primary tools for obscuring content:

  • Rectangle Redaction: Allows you to draw standard rectangular boxes over text blocks, table cells, or images.
  • Freeform Redaction: Enables you to draw custom, non-linear shapes over irregular content, signatures, or freehand elements.

The Redaction Workflow

Redaction in LibreOffice occurs in two stages to ensure accuracy before making permanent changes:

1. Draft Phase (Preview)

When you apply a rectangle or freeform shape, it initially appears as a semi-transparent gray box with a border. This allows you to verify that the correct content is covered without completely losing visibility of the underlying context.

2. Export Phase (Permanent Obfuscation)

Once all sensitive sections are marked, you must export the document to make the redactions irreversible. LibreOffice offers two export formats directly from the Redaction toolbar:

  • Redacted Export (Black or White): Converts the gray preview shapes into solid, opaque black or white blocks. This replaces the covered content with vector graphics in a standard PDF format.
  • Auto-Rasterized PDF Export: Converts the entire document into an image-based PDF. This merges all layers into flat pixels, ensuring that no underlying text layers, structural metadata, or original vector elements can be recovered using PDF inspection tools.

Best Practices for Safe Redaction

  • Always use the built-in export: Never attempt to redact text by changing the font color to match the background or placing standard drawing shapes over text in Writer. Those methods leave the underlying text searchable and copyable.
  • Choose Auto-Rasterized PDF for maximum security: If the document contains highly classified data, the rasterized export eliminates any chance of hidden document layers or embedded OCR data remaining in the final file.
