How to Split a LibreOffice Document into Chapters

Splitting a large LibreOffice Writer document into individual chapter files simplifies the management, editing, and formatting of extensive projects such as books and lengthy reports. This guide provides a straightforward method to automatically break a single .odt document into separate sub-documents using LibreOffice Writer’s built-in Master Document feature based on heading styles.

Step 1: Apply Heading Styles to Your Chapters

LibreOffice uses heading styles to determine where one chapter ends and another begins.

  1. Open your document in LibreOffice Writer.
  2. Navigate to the start of each chapter.
  3. Highlight the chapter title and set its style to Heading 1 using the Styles drop-down menu in the top toolbar or the sidebar.
  4. Ensure every chapter you want as a standalone file starts with the Heading 1 style.

Step 2: Export the Document into a Master Document

Once your headings are correctly configured, you can generate individual chapter files automatically:

  1. Click on File in the top menu.
  2. Hover over Send and select Create Master Document.
  3. In the dialog box that appears, choose a folder where you want to save the new files. It is best to create a new, dedicated folder to keep the generated files organized.
  4. In the Separated by drop-down menu at the bottom of the dialog box, select Heading 1 (or the corresponding heading style you applied in Step 1).
  5. Enter a name for the Master Document (.odm) in the File name field.
  6. Click Save.

Step 3: Access the Separated Chapter Files

LibreOffice will process the text and generate individual .odt files for every section that begins with the selected heading style:

  1. Open your file manager and navigate to the directory chosen in Step 2.
  2. You will find:
    • One Master Document (.odm), which links all chapters together.
    • Multiple separate LibreOffice documents (.odt), each named after the chapter heading and containing only that chapter's content.
  3. You can now open, edit, and share each chapter file independently. Any text occurring before the first Heading 1 will be saved as its own introductory sub-document.
